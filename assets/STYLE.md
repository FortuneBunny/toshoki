# 糖商記 SVG スタイルガイド

## 世界観
シルクロードとインド洋交易を下敷きにした架空の大陸。町は「糖」で動いている。
砂、琥珀、蜂蜜の暖かい色に、糖の結晶のきらめきを差し色として添える。
絵柄は**やわらかいフラットイラスト**: 輪郭線あり、影は1段だけ、ハイライトは小さく。かわいすぎず、写実でもない「ボードゲームの駒」くらいの情報量にする。

## 技術ルール（tools/validate-svg.js で検査される）
- ルート要素は `<svg xmlns="http://www.w3.org/2000/svg" viewBox="...">`。`width`/`height` 属性は付けない。
- viewBox は次のいずれか:
  - アイコン類（品物、輸送、地形、UI）: `0 0 64 64`
  - 町、建物: `0 0 128 128`
  - ロゴ: `0 0 512 256`
- 禁止: `<script>`、`<image>`、`<foreignObject>`、イベント属性（`onclick` など）、外部参照（`href="http..."`、`url(http...)`、`@import`）。グラデーションの内部参照（`url(#id)`）は使ってよい。
- 1ファイル 16KB 以下。目安は 1〜4KB。パスは整数か小数1桁に丸める。
- `id` はファイル名を接頭辞にして衝突を防ぐ（例: `honey-grad1`）。複数のSVGを1ページにインライン展開するため。
- テキスト（`<text>`）は使わない（ロゴのみ例外、ただし文字はパスにするのが望ましい）。
- 図柄は viewBox の内側に 4px の余白を取り、中央にまとめる。地面に置くもの（町、輸送）は下端から 6px 上を接地線にする。

## 配色（この中から選ぶ。近い色の追加はよいが、雰囲気を崩さない）
| 用途 | 色 |
|---|---|
| 輪郭線 | `#3b2618`（線幅: 64px 素材は 2.5、128px 素材は 3） |
| 砂（明/中/暗） | `#f3dfb3` / `#e2c08a` / `#b98c55` |
| 琥珀・蜂蜜 | `#f2a93b` / `#d9822b` / `#a65a1b` |
| 糖の結晶（白、ハイライト） | `#fffaf0` / `#c8f4ff` / `#7fd8f0` |
| 赤土・レンガ | `#c8553d` / `#8e3b2e` |
| 緑（オアシス、植物） | `#7bb662` / `#3f7f4a` |
| 水（川、海） | `#5bb4d6` / `#2f7fa8` / `#1d4e6e` |
| 紫（贅沢品、絹） | `#9b5de5` / `#6a3fa0` |
| 金（貴重品、ランク） | `#ffd166` / `#e0a526` |
| 銀（通貨） | `#e6e9ee` / `#a9b1bd` / `#6d7682` |
| 暗い影 | `#3b2618` を opacity 0.18〜0.25 で |

- 光は**左上**から。影は右下に、同系色の暗い色で1段だけ。
- 暗い背景（`#1c1712` 付近）と砂色の地図（`#e9d3a3` 付近）の**両方で見える**こと。輪郭線がそれを保証する。
- 甘味（糖を多く含む品）には、白とシアンの小さなきらめき（4点星か菱形）を1〜2個添えてよい。ただし小さく。
