# 開拓と糖度の版（版4）の計画

原作『Trade Empires』の序盤の作りを調べ直した結果を踏まえて、遊びの軸を組み替える。

- 作成日: 2026-10-22
- 前提: 全面マス目方式（`docs/PLAN-construction.md`）は完了・公開済み。交易所・開拓団・住居の求める品・需要施設・技術の仕組みは、ここから作り替えて使う。
- 状態: 計画（未着手）。柱の書き直しは、この計画の承認と同時に `docs/pillars.md` へ反映する。

## 0. 方針
| | 今（版3） | これから（版4） |
|---|---|---|
| 相場 | 他の町の値は、商人が最後に訪れたときの古い情報 | 一度訪れた町はいつも最新。読むのは「着く頃に町がどう変わっているか」（糖度の流れ） |
| 始まり | 最初からある町の1つに商人がいる | 一族（出発の地域）を選ぶ。市場のある町はない。集落・畑・野に立つ需要施設が散らばる土地に、最初の交易所を自分で置く |
| 値の決まり方 | 最初からある町どうしの値の差で稼ぐ | 自分の交易所の圏にいる家と需要施設の消費で、値が決まる（供給も需要も自分で作る） |
| 交易所 | 1500銀から、5割ずつ高くなり、2つまで。終盤のご褒美 | 安く、早く置くもの。交易所 → 市場 → 大市場と格上げして圏を広げる |
| 技術 | 効率が上がるだけ（5種類） | 新しい品と、それを求める需要が開く |
| 加工 | 多くが材料1つの一本道 | 離れた地域の品を合わせる加工を足す |

### 原作の序盤から分かったこと（プレイ動画の分析より）
- 始める前に、シナリオと一族を選ぶ。一族ごとに出発の地域が決まっている。
- 開始直後の地図には、住居・畑・需要施設（フォーラム、宮殿、造船所など）と、自分の一族の本部がある。市場・交易所は見当たらない。投稿者も「ここに市場を作って、この一帯を押さえる」と話している。
- つまり、家や需要施設は散らばっていても、それを「町」にまとめるのはプレイヤーの市場。画面の外の市場や、ライバルの一族が最初から市場を持つかどうかは分からない。
- 初心者向けの中国シナリオの説明では、手順が次のように示される。
  1. 雑穀のそばと米のそばに、交易所を1つずつ建てる。
  2. 2つの品を行き来させる路線を作り、商人3人に任せる。
  3. すると、交易所のまわりに住居が現れる。
  4. そのあと、絹 → 玉 → 青銅と、加工品の経済へ広げる。
- 交易所は安い。開始時の資金7,000に対して、交易所200・市場400・大バザール800。
- 住居が移ってくる条件は「食べ物4種＋ほかの品2種」のように、はっきり示される（難しいシナリオの例）。
- 得点は一族の富（所持金・商人・輸送手段・品物・自分の生産施設）。糖商記の資産とほぼ同じなので、ここは変えない。

**一番の発見**: 原作の最初の一歩は「2つの交易所で、違う食べ物を交換すると町が生まれる」。これは糖商記の「同じ食べ物ばかりでは育たない（食卓の多様さ）」とそのまま重なる。開拓の手触りと糖度の仕組みを、最初の数分で同時に教えられる。

## 1. 柱の書き直し案
柱1だけを書き直す。ほかの柱はそのまま残す。

- 今: **読みが当たる快感**: 古い情報から相場を読み、運び、当てる。判断の余地がない仕組み（いつも同じ答えになる最適解）は柱を壊す。
- 案: **読みが当たる快感**: 町の糖度の流れ（食卓の偏り、ラッシュとクラッシュ、ライバルの動き）から、着いたときの町の姿を読み、運び、当てる。判断の余地がない仕組み（いつも同じ答えになる最適解）は柱を壊す。

柱2には「町を育てる」の中身として、次の1文を足す。
- 自分で開いた交易所が、集落・町・都市へ育っていく。

**理由**: 町と路線が増えるほど、古い情報を覚えておく手間のほうが、判断の楽しさより大きくなる。定期便で自動化したあとは、情報の古さがほとんど効いていない。読む対象を「今は見えない値」から「これから変わる町」に移しても、柱1の判断の余地は保てる。

## 2. 相場の情報
- 自分の交易所は、いつでも最新の値と在庫が見える。
- 町ゼロの始まり方では、伏せるのは「まだ見ていない土地」だけ。集落・野の需要施設・資源は、本部や交易所の近くから順に見えてくる。探す楽しみと、置く場所を選ぶ判断を残す。
- ライバルの交易所と、残す場合の古い大都市は、一度訪れればいつでも最新の値が見える。
- 値の横に、町の状態を並べる。読む材料が糖度だと、画面から分かるようにする。
  - 糖度とその向き（上向き・下向き）
  - ラッシュ間近、ラッシュ中、クラッシュ中
  - 足りない食べ物（食卓の偏り）
- 値の動きを、糖度から予想できるようにする。
  - 偏った食卓の町では、足りない食べ物が日ごとに高くなる。
  - ラッシュ間近の町には、甘味の買い手が増える。
- 駅伝制（技術）は役目がなくなるので外し、4章の「品を開く技術」に入れ替える。
- 影響する所: `src/core/knowledge.js` を中心に、advice・panels・tradeDialog・world（画面）・CLI・ボット。目標の一言は、知っている情報だけで作る制限が軽くなる。

## 3. 開拓の序盤
### 始まりの流れ
1. シナリオを選ぶ。
2. 一族を選ぶ（＝出発の地域）。地域ごとに、近くの食べ物・資源・需要施設・道の具合が違う。
3. 地図に入ると、時間は止まっている。一族の本部（館）が出発の地域に立っていて、雇った商人はそこから出る。
4. 最初の交易所を置く。置ける場所は光り、圏に入るものを先に見せる。
   - 圏に入る集落の家の数と、その食べ物
   - 圏に入る畑と資源
   - 圏に入る野の需要施設と、それが求める品
   - 本部やほかの交易所までの日数
5. 交易所を置くと時間が動き出す。

### 地図
- **市場のある町はない。** 散らばっているのは次のものだけ。
  - **集落**: 家が数軒と畑。それぞれ1〜2種類の食べ物を作り、少しだけ食べる。集落のままでは育たない。
  - **野の需要施設**: 古い寺院、隊商宿、領主の館など。決まった品（食べ物・甘味・塩・茶など）を求める。家はない。
  - **資源のマス**: 今と同じ（サトウキビの湿地、ヤシの泉、塩田など）。
- 集落と野の需要施設は、交易所の圏に入ると、その交易所の住人と買い手になる。
- 集落の配置は、どの出発の地域にも「違う食べ物を作る集落が、近くに2か所以上ある」ようにする。序盤がからっぽになるのを防ぐため。
- 後半のシナリオでは、遠くに古い大都市を1つだけ残してもよい。白糖や菓子を高く買う「外の大口の買い手」にする。町を1つも置かない形でそろえるかは、試してから決める。

### 値の決まり方
- 交易所の値は、圏にいる家の数・食卓・糖度と、圏に入った需要施設の求めで決まる。今の町の価格の仕組み（在庫が少ないほど高い）をそのまま使う。
- 供給も需要も自分で作る、閉じた経済になる。原作も同じ形。
- 稼ぎは「余っている交易所から、足りない交易所へ運ぶ」ことから生まれる。どこに何が足りなくなるかを糖度の流れから読むのが、柱1の判断になる。

### 最初の収入
- 交易所を置いても、家が建つまでは売り上げがほとんどない。
- 野の需要施設を、序盤の確かな稼ぎ先にする。圏に入れると、求める品を安定して買ってくれる。
- 「需要施設を圏に入れるか、畑のある集落を入れるか」が、交易所を置く場所の判断になる。
- 開始の銀で、交易所2つと商人数人を、家が建ち始めるまで（数十日）まかなえるようにする。

### ライバル
- サルマン商会も、自分の本部から交易所を開いて育てる。
- 同じ集落・同じ需要施設を取り合う。圏が重なったマスは、今と同じく近い交易所に属する。
- 原作の一族どうしの争いに近づく。ライバルの交易所の置き方は、ボットで確かめる。

### 交易所の格
| 格 | 費用の目安 | 圏 | 中身 |
|---|---|---|---|
| 交易所 | 安い（開始の銀の1〜2割） | 小さい | 品の集荷と売買。家が建ち始める |
| 市場 | 中くらい | 広い | 工房・需要施設を建てられる。荷車を買える |
| 大市場 | 高い | もっと広い | 宮殿などの大きな需要施設を建てられる |

- 格上げは、今の「市場の圏の拡張」を使う。
- 交易所の数の上限は、今の「2つまで」をやめ、費用の上がり方で抑える。
- 開拓団（大きな町から人を運ぶ）は、中盤に交易所を早く育てる手段として残す。

### 最初の目標（序盤の手引き）
- 「違う食べ物のそばに交易所を2つ置き、定期便で行き来させる」
- 食卓が多様になって糖度が上がり、家が建ち始めるところまでを、最初の数分で見せる。

## 4. 段階と、技術で開く品
### 段階の道しるべ
シナリオの説明と目標の一言で、経済の段階を先に見せる。
- 食べ物 → 粗糖 → 白糖 → 菓子・砂糖細工
- 「使えるようになったら届けよう」が、中盤の目標になる。

### 品を開く技術
今の技術（効率が上がるだけ）の一部を、新しい品と需要を開く技術に置き換える。
- 例: 「精製の秘法」で、白糖の精製を開く。
- 例: 「砂糖細工の技法」で、砂糖細工を開く。開くと宮殿がそれを求め始める。
- 開いたときに「新しい品が求められている」と大きく知らせる（柱4）。
- ライバルのいるシナリオでは、先に買った側がその品の加工を独占する。相手は使用料を払う。「新しい市場の先取り」の争いになる。

### 合わせの加工品
- 離れた地域の品を2つ合わせて作る品を、1〜2種類足す（例: 白糖＋香辛料、水飴＋茶）。
- 長い定期便の路線を組む理由を作るため。
- 値段は、加工の取り分を据え置いた経緯（`docs/balance-log.md`）を踏まえて、ボットで確かめてから決める。

## 5. 需要施設
- 寺院・学問所にも「求める品が高く売れる」効果を付ける。今は宮殿（+15%）と茶館（甘味の需要+10%）だけ。
- 終盤に余る銀の使い道にもなる。
- いつも同じ答えにならないよう、ボットで確かめる。

## 6. 小さな改善
- **定期便の写し**: 「この定期便を別の商人に写す」ボタン（原作の路線の一覧の良い所だけを取る）。
- **施設の動きを地図で見せる**: 工房と生産施設が動いているか、止まっているかを、煙や動きで見分けられるようにする。

## 7. 取り入れないもの
- 路線を商人と別に保存し、「保存 → 割当 → 出発」の3段にすること。原作でも、開始直後に警告が出るなど、つまずきやすい。
- 積荷を2〜4個の枠で決めること、左クリックで足して右クリックで外す操作。量で値が動くことが中心なので、今の数量入力を残す。
- よその生産者に代金を払うこと、生産者を買い取ること。
- 戦争・兵舎・武器。
- 地域ごとの地図の切り替え、文化ごとの建物の見た目。
- ライバルの一族を増やすこと。
- 「食べ物4種＋ほかの品2種」のような重い条件で始めること。中国シナリオの「2拠点・2食料」の小ささを手本にする。

## 8. シナリオへの当てはめ
- フリープレイと新しい手引きは、町ゼロ（集落と野の需要施設だけ）で始める。フリープレイで先に試す。
- s1（手引き）は、3章の「2つの交易所をつなぐ」序盤に作り替える。
- うまくいけば s2 以降も町ゼロの始まり方へ広げる。後半のシナリオで「外の大口の買い手」として古い大都市を1つ残すかは、試してから決める。
- s8（交易所を町に育てる）は、元々この遊びに近い。目標の数値を見直す。
- 目標の型は、町を育てる目標（人口、段階）を「自分の交易所を育てる」目標に読み替える。最初からある町を指定する目標は使えなくなる。
- どのシナリオも、出発の地域ごとの達成日数をボットで出し、どの地域にも勝ち筋があるか（差が大きすぎないか）を確かめる。

## 10. 危険と対策
| 危険 | 対策 |
|---|---|
| 相場がいつも見えると、一番儲かる往復が計算で決まる | 値を糖度の流れで動かす。ライバルと事件で、着く前に状況が変わるようにする。ボットとテスターで確かめる |
| 序盤がからっぽになる | どの出発の地域にも、違う食べ物の集落を2か所以上と、野の需要施設を置く。開始の銀で、家が建ち始めるまでまかなえるようにする |
| 町がないと、値の差が生まれず稼げない | 交易所の値を圏の家・食卓・需要施設の求めで動かす。地域ごとに採れる食べ物を偏らせて、運ぶ理由を作る |
| 閉じた経済で、ライバルと取り合うものがない | 集落と野の需要施設を取り合う形にする |
| 最初の場所選びが、いつも同じ答えになる | 候補に一長一短を付ける。出発の地域ごとの達成日数をボットで比べる |
| 悪い場所を選ぶと、ずっとあとで詰んでいたと分かる | 交易所を安くして、2つ目以降で取り返せるようにする。置く前に、圏に入るものを見せる |
| 調整済みのバランスが崩れる | H0〜H1 は今のシナリオのまま入れて、ボットで差を見る。H2 はフリープレイで先に試す |
| 古いセーブが読めない | 版3のセーブは、新しい始まり方では読み込めないと表示する。キャンペーンの達成記録と家訓は残す |

## 11. 決めること
- まだ見ていない土地を、どこまで伏せるか（最初から地図全体の地形は見せて、集落と需要施設だけ伏せるか）。
- 野の需要施設の種類と、求める品・買う量。
- 集落の家の数と、交易所の圏に入ったときの最初の人口。
- 後半のシナリオに、外の大口の買い手として古い大都市を1つ残すか。
- 開始の銀と、本部の役割（商人の出発点のほかに、倉庫や工房を置けるか）。
- ライバルの交易所の置き方（先に良い場所を取るか、プレイヤーと離れた所から育てるか）。
- 交易所・市場・大市場の費用と圏の広さ。
- 品を開く技術を、今の5つのどれと入れ替えるか。合わせの加工品を何にするか。
- s1 を作り替えるか、新しい手引きのシナリオを足すか。

## 12. 完了の定義
- 柱1が書き直され、相場はいつも最新（まだ見ていない土地を除く）で、読む材料が糖度の流れになっている。
- 一族を選び、町のない土地に最初の交易所を置いて、町を育てる始まり方が、ブラウザ版と CLI 版の両方で遊べる。
- 品を開く技術と、合わせの加工品が入っている。
- 単体テスト・ブラウザの自己テストが通る。
- 全シナリオのボット回帰で、放置では達成できない。どの出発の地域にも勝ち筋がある。
- 全員テストで、開拓の序盤が「楽しい判断」と評価され、必勝法の報告がない。
- `docs/balance-log.md`、`playtests/`、README を更新し、公開ページに反映する。
