# 設計の意図（画面だけのテストで確かめる表）

画面だけのテストでは、気持ちよさを5段階で付けてもらう代わりに、この表の意図ごとに「遊んでそうなっていたか」を判定してもらう（6回目から）。
- 判定: ○ そうなっていた／△ 一部だけ／× なっていない／― そこまで届かなかった
- ○ のとき: 画面のどの部分、どの場面で、そう感じたか（日付・写真）。
- △・× のとき: 崩れている層（決まり・操作・知らせ・数値・配置）と、どこをどう変えるか。

番号は、テストの記録と直しの記録で使う。柱は `docs/pillars.md` の番号。

## 共通
| 番号 | 層 | 意図 |
|---|---|---|
| C1 | 決まり | 目標と今の進み具合が、いつでも画面で分かる。何をすれば近づくかが、目標の欄か町の画面から分かる。 |
| C2 | 操作と知らせ | 押した結果（売上・積荷・備蓄の日数・出発の見込み）が、その場で返る。同じ押し方を10回以上くり返す作業がない（柱5）。 |
| C3 | コアループ | 1便ごとに「何を積むか・いつ出るか・どこで売るか」の判断がある。答えが毎回同じではない（柱1）。 |
| C4 | ミドルサイクル | 町に届けた食べ物と甘味が、30日ほどの単位で、備蓄の日数・人口の増え・節目として返ってくる。自分が町を育てた手応えがある（柱2）。 |
| C5 | 緊張と解放 | 予告から本番までは身構え、本番を越えると解放される。その間は、商いと町育てに戻れる。止めたい日に止められ、待つだけの時間が長くない。 |
| C6 | 失敗の理由 | 損をしたとき、遅れたときに、原因（どの知らせを見落とした、どの便、どの判断）が画面で分かる。原因が自分の判断の中にある。 |
| C7 | 次の報酬 | 次に届く節目（目標の残り・人口の節目・格上げで開くもの）が、いつも見えている。 |
| C8 | 自動化の先 | 定期便に任せたあとも、予告に手を打つ場面が残っている（柱5）。 |

## s4 砂の海
34回目の相談で強盗団の予告を外し、予告のないシナリオにした（S4-3〜S4-5・S4-7 は書き直した。6回目までのテストの番号とは中身が違う）。s4 では、共通の C5 は「甘味を重ねた伸びと、その反動」、C8 は S4-5 で見る。

| 番号 | 層 | 意図 |
|---|---|---|
| S4-1 | 自然な誘導 | 序盤にすること（オアシスに交易所を開く → ラクダと食料を整える → 玻璃の都の絹を緑門へ運ぶ）が、長い文を読み込まなくても画面から分かる。 |
| S4-2 | ギミック学習 | 砂漠の旅の決まり（隊商が食料を食べる・ラクダが要る・盗賊と護衛）を、最初の1〜2便の小さな損で学べる。定期便の護衛の数も、目安から決められる。 |
| S4-3 | コアループ | 絹の便の行きと帰りに、オアシスへ何を落とすか（麦・ぶどう・甘味）を選ぶ。その答えが、オアシスの食卓（備蓄の日数）と絹の値で毎回変わる。 |
| S4-4 | 甘い誘惑 | 甘味を届けると育ちが大きく伸びる。届けすぎや、ラッシュの反動の代償が、目標までの残りの日数と一緒に画面で分かる。 |
| S4-5 | 自動化の先 | 定期便に任せたあとも、食卓の切れ・盗賊の損・絹の値の知らせで、便を組み替える場面が残る。 |
| S4-6 | 町を育てる | オアシスはなつめやしと塩しか採れないので、麦・ぶどう・甘味を届けると育つ。それが届けた量と備蓄の日数（圏の隊商宿が先に買う分も引いた日数）で読め、格上げでぶどうの泉を取り込む一手が見える。 |
| S4-7 | 難易度 | 手で1便 → 定期便 → オアシスの格上げと食卓の組み立て、と段階を踏む。予告はなく、s3 と s5 の間の一息にあたる。 |

## s6 季節風の港
| 番号 | 層 | 意図 |
|---|---|---|
| S6-1 | 自然な誘導 | まず白檀港を「都市」に育て、それから香辛料を運ぶ、という順が序盤に分かる。 |
| S6-2 | ギミック学習 | 季節風（夏は東へ、冬は西へ）で着く日が変わることを、出発の画面の日数で学べる。 |
| S6-3 | ギミック学習 | 最初の港の市（試しの市・15袋まで）で、市の決まり（直に着いた船・市の間に着く）を、小さな得で学べる。 |
| S6-4 | 読みが当たる | 2回目からの港の市では、季節風の日数を読んで、市の間に着くように出られる。出る日が予告と季節で変わる。 |
| S6-5 | 失敗の理由 | 市で売れなかったとき、理由（市の前に着いた・直でない・まだ都市でない・試しの分を売り切った）が分かる。 |
| S6-6 | 町を育てる | 米と甘味を白檀港に届けて都市に近づくのが、人口の増えと節目で分かる。 |
| S6-7 | 決まりの一致 | 交易で稼ぐことと、目標（香辛料200袋・資産9000）に近づくことが離れていない。 |
