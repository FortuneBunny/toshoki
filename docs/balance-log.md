# バランス調整の記録

変えたこと、採用しなかった要望、その理由を残す。判断の基準は `docs/pillars.md`。

## 2026-10-20 ボットによる初期調整
- **何もしなくても町が育ちすぎる**: 町が自分の特産だけで糖度を上げられていた。
  - 1種類の食べ物が満たせる糖度を必要量の50%までにした（`singleFoodCap`）。食卓の多様さ＝交易が成長の鍵になる（柱2）。
  - 1種類の甘味の効き目も40%までにした（`singleSweetCap`）。ラッシュには複数の甘味が要る（柱3）。
  - 糖度が低いうちの成長を二乗の曲線にした（糖度50ではほぼ育たない）。
  - 背景の交易（見えない商人による平準化）は余剰分だけを、0.6%/日で流す。
- **s2 で何もしないボットが「麦の里を町に」を達成**: 麦の里の蜂蜜生産をやめ、甘蔗の浜へ移した。期限を 480 → 360 日、資産目標を 2000 → 3000 に。
- 結果: 何もしない・甘味だけ・儲けだけのボットは s2 を達成できず、目標を意識するボットは達成する。

## 2026-10-20 全員テスト1回目の反映
詳細は `playtests/round-1.md`。
- 読み的中: 手動の旅で予想より15%以上高いときだけ。評判 +15。
- 大口注文: 数量は商人の積載合計の8割まで、期限は往復できる日数以上。
- 事件の発生率: 3.5% → 5%/日。
- s1 の S 基準 50% → 35%、s2 の S 基準 50% → 40%。
- 一族の援助（一度きり）を追加。
- **採用しなかった**: 全体の難易度を上げること（序盤の2シナリオは導入のため）、何にでも止まる wait。

## 2026-10-20 シナリオ3〜8の追加とボットによる確認
- **荷車の罠**: 小道しかない町で荷車を買うと、どこへも行けなくなっていた。通れる道が1本もない町では、その輸送手段を買えないようにした。
- **砂漠が過酷すぎる**: ロバの隊商が砂漠を渡る間に、積載量のすべてを食料として食べていた。食料の消費を「積載60ごとに1日1個」に、食料切れの損失を8% → 3%/日に、盗賊の頻度を半分に。危険度2の道でも、護衛が3人いればたいてい撃退できる強さにした。
- **流行（新しい事件）**: ある町で特定の品が60日間よく売れる。定期便を組み替える理由をつくるため（全員テスト1回目の「中盤が単調」への手当て）。
- 大口注文の頻度 2% → 3%/日。

## 2026-10-20 全員テスト2回目（途中）の反映
- **シュガーラッシュが起こせない（Sol、荷車4台・銀4万6千でも0回）**: 柱3の中心が手の届かない状態だった。
  - 起きる条件を「糖度140以上」かつ「その日の甘味の摂取が必要量の85%以上」に変更（甘味2種類以上をまとめて届けると起こせる）。
  - 甘味1種類の効き目の上限 40% → 45%、効き目の倍率 0.85 → 1.0、糖度の反応の速さ 0.12 → 0.2。
  - 町の準備期間に起きたラッシュを回数に数えていた不具合を修正。
  - 放置で起きるラッシュは全シナリオでほぼ0回（s2 だけ年4回あったので、甘蔗の浜の蜂蜜を琥珀京へ移した）。
- **町に何をどれだけ届ければいいか分からない（Haiku、Sol、Luna）**: 町の画面に「伸びしろ」（品ごとに、1日あと何個届けると糖度がどれだけ上がるか）と、甘味の摂取量を表示。
- **初心者がシナリオ3で製糖所まで届かない（Haiku）**: 序盤の目標（初心者でも必ずクリア）を満たしていない。製糖所の使い方を手引きの手順にし、開始時の銀 450 → 750、製糖所 600 → 450 銀、白糖の目標 250 → 200、資産の目標 6000 → 5000 に。
- **工房の自動仕入れで銀が尽きる（Haiku）**: 手元の銀が300を切ると止まるようにした。
- 目標の品をまだ買い取らない町では「町が育つと買い取る」と目標欄に表示（Sol、s6）。

## 2026-10-20 全員テスト3回目の反映
詳細は `playtests/round-3.md`。
- 状態の目標（銀・資産・人口・町の段階）は、全部の目標がそろう瞬間に満たす条件に（一度の達成で残すと、寄進で資産を減らす抜け道になった）。積み上げ型（生産・販売・ラッシュ）は一度届けば達成のまま。
- s3: 製糖所をサトウキビの産地に建てる手引きに変更。工房の自動仕入れで残す銀 300 → 100。S の基準 45% → 33%。
- **採用しなかった**: s8 で全要素を使わせる副目標（道具の選択はプレイヤーに任せる）、s4 の往復の短縮（砂漠越えが主題）。

## 2026-10-20 家訓の作り直し
- **問題**: 家訓は全部が上乗せで、重ねがけできた（8シナリオで最大7個）。後半ほど簡単になり、プレイテストは主に家訓なしで調整していたため、家訓を積んだ状態の難しさは未検証だった。シミュレーションゲームの永続強化でよく批判される「強さのインフレ」と「正解が1つになる選択」の形。
- **変更**:
  - 家訓は**シナリオを達成すると、そのシナリオに対応したものが1つ解放**される（s1〜s7 で7種類）。
  - シナリオの最初に、解放済みの家訓から**1つだけ**選ぶ（家訓なしも可）。重ねがけはしない。
  - どの家訓にも**利点と代償**を付けた（例: 健脚 = 移動+12% / 積載-15%、元手 = 開始時の銀+500 / 毎日3銀の利子）。
- **確認（ボット、各6シード）**: どの家訓も、家訓なしより少し有利な程度。強い家訓は場面で変わる（工房の s3 では職人気質、海の s6 では商才、s2 では健脚）。一つが常に最善になる状態ではない。健脚の資産の伸びがやや大きいので、次の調整候補として記録する（ボットは積載の上限まで積むことが少なく、代償が効きにくい可能性もある）。
