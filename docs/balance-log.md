## 2026-10-20 家訓の作り直し
- **問題**: 家訓は全部が上乗せで、重ねがけできた（8シナリオで最大7個）。後半ほど簡単になり、プレイテストは主に家訓なしで調整していたため、家訓を積んだ状態の難しさは未検証だった。シミュレーションゲームの永続強化でよく批判される「強さのインフレ」と「正解が1つになる選択」の形。
- **変更**:
  - 家訓は**シナリオを達成すると、そのシナリオに対応したものが1つ解放**される（s1〜s7 で7種類）。
  - シナリオの最初に、解放済みの家訓から**1つだけ**選ぶ（家訓なしも可）。重ねがけはしない。
  - どの家訓にも**利点と代償**を付けた（例: 健脚 = 移動+12% / 積載-15%、元手 = 開始時の銀+500 / 毎日3銀の利子）。
- **確認（ボット、各6シード）**: どの家訓も、家訓なしより少し有利な程度。強い家訓は場面で変わる（工房の s3 では職人気質、海の s6 では商才、s2 では健脚）。一つが常に最善になる状態ではない。健脚の資産の伸びがやや大きいので、次の調整候補として記録する（ボットは積載の上限まで積むことが少なく、代償が効きにくい可能性もある）。

## 2026-10-21 製糖所＋菓子工房の連鎖（11回目の Opus の指摘）
- **問題**: s8 で、甘蔗平原の製糖所 → 琥珀京の菓子工房 → 菓子を売る1本の定期便だけで累計 +43000銀（利益の半分近く）。資産25000の目標を223日目に「あっさり」超えた。
- **原因（試算で確認）**: 菓子は1日3個ほどしか作れないのに、琥珀京（人口9000、茶館と寺院あり）は菓子を1日10個以上欲しがる。茶館と寺院だけで人口1000人あたり0.8個の需要が足される。在庫がいつも0に近いので、作った分が毎回ほぼ上限値（基準の約2.2倍）で売れていた。売り先1つで値崩れが起きないので、考えることがなかった。
- **変更**:
  - 菓子づくり: 白糖1＋麦1 → 菓子2 を、**白糖2＋麦2 → 菓子3** に。白糖1個から作れる菓子が2個から1.5個に減る。麦も多く使うので、麦の仕入れが本当に足かせになる（Opus の菓子工房も麦切れで止まっていた）。
  - 菓子の基準値 46 → 40。値打ちは材料より上のまま（白糖2＋麦2 = 92 → 菓子3 = 120）。
  - 菓子の消費 人口1000人あたり 0.5 → 0.3。茶館や寺院のない町では1日2個ほどで値が下がり始めるので、量を売るには売り先を2〜3つに分けるか、茶館のある町を選ぶことになる。
  - 菓子工房の建設費 900 → 1200銀（2つ目の工房を建てるかどうかが判断になるように）。
- **確認（s8 の試算、230日、5シード）**: 菓子工房を琥珀京に置き、白糖をただで運んだと仮定（実際の運びや麦切れの分は、ここより下がる）。

  | 条件 | 前 | 後 |
  |---|---|---|
  | 茶館・寺院あり、精製の秘法なし（Opus に近い） | 262銀/日 | 166銀/日 |
  | 同、精製の秘法あり | 338銀/日 | 216銀/日 |

  参考: 製糖所だけ（白糖のまま琥珀京で売る）は 120銀/日。普通の交易路（ラクダの絹便、荷車の米便）は、初回でも 45〜70銀/日、続けると下がる。連鎖はまだ一番の稼ぎ頭。

## 2026-10-21 終盤に銀が余る（6回目から継続）: 商館と銀の使い道の案内
- **調べたこと**: 10〜11回目の長いシナリオ（s5〜s8・フリープレイ）の30回分。上手い役は s8 で操作のあいだに7〜11万銀を稼ぎ、寄進を除く投資は1万〜1.5万だった。下手な役も1.5万〜6万を余らせたまま未達（Haiku の s8: 2万銀・商人3人・都の糖度53）。何度でも使える使い道は寄進だけで、全員の支出で一番多かった。
- **原因**: 10回目の Opus の s8（633日目、銀10万、琥珀京5632人）から200日動かして比べた。周りの町の生産2倍 → 変化なし（産地には在庫が余っていた）。寄進を切らさない（2.95万銀）→ 7307人が7662人。同じ定期便を6本足す → 8170人。足りないのは運ぶ量で、商人の上限に当たると、銀を運ぶ量に換える手段がなかった。
- **商館**（s5〜s8・フリープレイ）: 「町」以上の町に1つずつ。雇える商人 +1、その町の倉庫が使え、相場がいつでも分かる。3000銀から倍々（3000・6000・12000…）、維持費5銀/日。同じセーブで商館3つ（輸送手段と合わせて2.2万銀）と足りない品の便を足すと、届かなかった大都市に817日目で届いた。
- **銀の使い道の案内**: 銀が眠っているとき（毎日の出費60日分と1000銀を残して1500銀以上）、status と画面に、雇える人数・商館・寄進と、目標の町に足りない品（住居の求める品、食卓に足りない品とその産地）を出す。
- **採用しなかった**: 寄進の重ねがけ（銀で成長を買うことになり、柱2に反する）、費用や維持費の全体の引き上げ（判断が増えない）、商人の上限の撤廃（操作が重くなり、ライバルとの釣り合いが崩れる）。

## 2026-10-21 敵対的評価（12回目）の反映

- **同じ売りの行を並べると、1個を何個にも売れた**（Sol: 白糖1個を320個売ったことにして s7 を26日目に S）。同じ品の行はまとめてから確かめる。

- **全部売ると、同じ町での売り戻しが販売数に数えられた**（Sol）。判定の順番を直した。
- **ライバルが琥珀京で止まったまま**（Opus の「絹の便がいつも同じ答え」の原因）。運ぶ物のない町では、空荷で仕入れ先へ移る。s8 の琥珀京の絹は、ずっと142だったのが62〜142で動くようになった。あわせて、間の町がその品を買わないときは、1つ先の町とも背景の交易が流れる。
- **菓子工房が大都市で麦切れのまま止まる**（Opus: 白糖1,074個が倉庫に眠った）。米でも作れるレシピ（白糖2＋米2→菓子3）を足し、止まった工房の倉庫に眠っている材料を status に出す。
- **資産**: 積荷も倉庫と同じく「その町（移動中なら行き先）で売った値の8割」で数える（積み替えで資産が増えた）。商館は払った額の半分を資産に入れる。
- **商館の相場**は5日ごとに届く（いつも最新だと、古い情報で読む面白さが薄れる。Opus）。
- そのほか: 暇を出したあとの雇用で商人の番号が重なった（Sol）。7人目からの名前の重なり（両方）。定期便の商人が砂漠で飢えても wait を止めない。案内が交易所の目標とラッシュの目標を見るようにし、産地の余りの範囲で量を勧める。

  - 交易所に格を付けた: 交易所（圏2マス）→ 市場（4マス、900銀）→ 大市場（6マス、2400銀）。格上げは、今の「市場の圏を広げる」のボタンと `expand` から行う。
  - 交易所の圏は町の段階では広がらない。交易所のままだと、家の建つ空き地で人口が1000前後で頭打ちになる。
  - 工房と需要施設は「市場」から、宮殿は「大市場」から建てられる。
  - 古いセーブの交易所は格がないので、今までどおり（町の段階で圏が広がり、市場として扱う）。

## 2026-10-22 開拓と糖度の版 H3: 技術で開く品と、合わせの加工品
- **理由**: 原作では、技術を取ると「新しい品を宮殿や寺院が求めている」と知らせが出て、経済の段階が進む。糖商記の技術は効率が上がるものだけで、中盤に「次はこれを開く」という目標がなかった。
- **変えたこと**:
  - 技術に「開くもの」を持たせた（作り方・工房・生産施設・品）。シナリオにその技術があると、だれかが買うまで、その品はどの町でも求められない。買うと「新しい品が町で求められるようになった」と大きく知らせる。
  - ライバルが先に買っても需要は開くが、作るには使用料が要る。ライバルは、品を開く技術も買えるようになってから45日後に買う。
  - 品を開く技術: 白糖の精製法・菓子の技・砂糖細工の技法・香辛糖の秘伝・茶の湯の作法。
  - 合わせの加工品を2つ足した。どちらも菓子工房で作る。
    - 香辛糖: 白糖1＋香辛料1 → 2個（基準68銀）。宮殿が求める。
    - 茶菓子: 茶1＋蜂蜜1 → 2個（基準30銀）。茶館が求める。
  - s8 に、砂糖細工の技法（0日目から）・茶の湯の作法（60日目から）・香辛糖の秘伝（120日目から）を入れた。s8 の砂糖細工は、技術を買うまで求められなくなった。
  - 需要施設で値が上がる品を増やした: 寺院と学問所も、求める品が10%高く売れる（宮殿は今までどおり15%）。
  - 工房の作り方は、産物もシナリオにある品だけ使う（前は材料だけ見ていたので、砂糖細工がないシナリオでも都市の菓子工房が砂糖細工を作りうった）。
- **ボットの結果（各10シード）**: s5・s8 は前とほぼ同じで、放置では達成できない。

## 2026-10-22 開拓と糖度の版 H2・H4・H5: 町のない土地から始める
計画は `docs/PLAN-pioneer.md`。原作の開始時は、家・畑・需要施設が散らばっていて、それを自分の市場でまとめて経済を始動させる形だった。初心者向けの中国シナリオは「違う食べ物のそばに交易所を2つ建てて、行き来させると家が現れる」から始まる。
- **H2 町のない始まり方**（s1 とフリープレイ）:
  - 一族を選ぶと館の立つ地域が決まる（フリープレイは3つ、s1 は1つ）。ライバルは選ばなかった一族の館から始める。
  - 館から14マス以内の、集落を圏に入れられる場所に、最初の交易所を無料で置く。置くまで時間は進まず、置くと商人が館から出てくる。
  - 集落（家が数軒と畑）は、交易所の圏に入るとその交易所の住人になり、畑は生産施設になる。集落のままでは育たない。
  - 野の需要施設（古い寺院・隊商宿・領主の館）は、圏に入ると、求める品を人口によらず毎日決まった量だけ買う。町の人の糖度には入らない。
  - ライバルも8日目・170日目・360日目に交易所を開き、まわりの集落を取り込む。ライバルの交易所は人口で市場・大市場になる。だれでも売り買いできる。
  - 町のない土地では、交易所どうしは8マス以上あければよい（ほかのシナリオは14マス）。道がなくても開ける。
- **規模の調整**（決まった往復だけをするボットで確かめた）:
  - 最初は集落の人口を100〜200、作る量を必要量の1.4倍ほどにしたが、交易所が小さすぎて売り買いの量が少なく、糖度が7〜135の間で大きく揺れ、銀が給金で減り続けた。
  - 集落を s1 の町と同じ規模（館のそばは人口260〜420、作る量は糖の必要量の1.8〜2.2倍）にした。2つの交易所の往復だけで、500日で銀が1100→6740、両方の交易所が人口750ほどに育つ例が出た。
  - 館のそばには、違う食べ物を作る集落を2つ必ず置く（サトウキビは甘味なので、食べ物の2つ目にはしない）。2つ目の集落のそばに野の需要施設を1つ置く。
- **フリープレイ**: 町ゼロの地図に作り替えた（集落18・野の需要施設7）。目標は「人口3000の交易所」「人口300以上の交易所を4つ」「資産15000銀」、期限1080日。白糖・菓子は技術で開く（60日目・120日目から）。開始の銀は1500。
  - 開拓のボット（交易所を開く・格上げ・小道・製糖所・技術）は、8シードで達成率0%だが、目標の進み具合は平均68%・78%・31%。放置は15%・25%・0%。
