# 建設要素の追加計画（全面マス目方式）

Trade Empires（2001）の「町も道も施設も自分で作り、それを交易でつなぐ」手触りを再現するため、**地図全体をマス目（タイル）にする**。町と町の間の移動も、マス目の上の経路探索で行う。

- 作成日: 2026-10-20（区画方式から全面マス目方式へ改訂）
- 前提: 本編は完成・公開済み。区画方式の D0〜D3（区画の生成、配置、住居と労働力、需要施設）は実装済み。この仕組みは捨てずに、世界のマス目の上へ載せ替える。

## 0. 方針
| | 今（路線図＋町の区画） | これから（全面マス目） |
|---|---|---|
| 地図 | 町＝点、道＝線。町の中だけ 12×12 の区画 | 地図全体が1枚のマス目（目安 160×100） |
| 移動 | 道（線）の上を、決まった日数で | マス目の上を経路探索。道の種類と地形で速さが変わる |
| 道 | 最初から決まっている。小道を街道に整備できるだけ | プレイヤーがマス単位で敷く（小道・街道・運河・港）。既存の道は最初から敷かれている |
| 町 | 最初から決まっている | 最初の町に加えて、交易所をどこにでも開ける（条件あり） |
| 建物 | 町の区画の中 | 町（市場）の影響圏の中の、世界のマス目に直接置く |

**柱との関係**
- 柱1（判断）: どこに道を通し、どこに町を開き、どこに何を建てるか。地形（砂漠、山、川、海）がそのまま判断の材料になる。
- 柱2（町を育てる手応え）: 家が地図の上に広がっていく。町の姿がそのまま成長の証になる。
- 柱5（自動化の先の判断）: 定期便を組んだあとに、道と町を設計する層がある。全員テストで毎回出た「待つだけ」への根本的な答え。

**原作の反省への対処**
- 原作の開発者が最も悔やんだのは、地形を自由に歩かせる経路探索の難しさだった。今は A* で十分に解ける（マス数は1万6千程度）。経路はキャッシュし、道や地形が変わったときだけ計算し直す。
- 道なき移動（ロバ・ラクダで地形を直接進む）は残すが遅くする。道を敷く価値をはっきりさせるため。
- 細かい管理は強いない。住居と生産は自動で動く。道は「始点と終点を選ぶと自動で経路を引く」操作を用意する。

## 1. 世界のマス目
- **地形**: 平地、肥えた土地、砂地（砂漠）、丘、山（通れない）、水（海・湖）、川（船と渡し）。
- **資源のマス**: 今の区画と同じ種類（サトウキビの湿地、ヤシの泉、塩田、鉱脈、茶の斜面など）。土地に合ったものだけ（全員テスト4回目の必勝法の対策をそのまま引き継ぐ）。
- **生成**: シードとシナリオの指定から作る。シナリオには、町の位置、海・砂漠・山の大まかな形（今の `shapes` を拡張）を書く。細部は決まった乱数で埋める。
- **保存**: 地形はシードから作り直せるので保存しない。保存するのは変化（道、建物、町）だけ。

## 2. 移動と経路探索
- 商人は A* で経路を探し、マスを1つずつ進む。1マスにかかる時間は「地形 × 道の種類 × 輸送手段」で決まる。
  | | 道なし | 小道 | 街道 | 運河・川 | 海 |
  |---|---|---|---|---|---|
  | ロバ・ラクダ | 遅い（砂地はラクダのみ普通） | 普通 | 普通 | × | × |
  | 荷車 | × | × | 速い | × | × |
  | 船 | × | × | × | 速い | 季節風しだい |
- 季節風は、海のマスで進む向きによって速さが変わる。砂漠のマスでは食料を食べる。盗賊は「危険な地域」のマスで出る（今の道の危険度を地域に置き換える）。
- 今の道の日数と同じくらいになるように、マスあたりの時間を合わせる（G0 で調整）。

## 3. 町と市場の影響圏
- 町（市場）は世界のマスに立ち、まわりに**影響圏**（町の段階で半径が広がる）を持つ。
- 区画で作った仕組みを、影響圏の中の世界のマスでそのまま使う:
  - 生産施設（資源のマスに置く、建設10日、維持費）
  - 住居の自動建設と人口の上限
  - 労働力
  - 需要施設（茶館・寺院・学問所・宮殿）
- 影響圏が重なる町どうしでは、同じマスを取り合う（近い町に属する）。

## 4. プレイヤーが作るもの
- **道**: 小道（安い、ロバ・ラクダ）、街道（荷車が通れる）、運河（船が内陸へ）、港（陸と海をつなぐ）。始点と終点を選ぶと、費用が最も安い経路を自動で引く（マスを1つずつ選んでもよい）。費用は長さと地形しだい（丘は高い、山は通れない）。
- **交易所**: 地図のどこにでも開ける。ただし、ほかの町から一定の距離をあけること、道か海に面していること。開くと新しい町（集落）が生まれ、まわりの資源を活かせる。
- **生産施設・工房・需要施設**: 町の影響圏の中のマスに置く。

## 5. 画面と CLI
### ブラウザ
- 地図は canvas の斜め見下ろし。ドラッグで移動、ホイールで拡大・縮小。
- 拡大すると町の家や施設、縮小すると地域全体と定期便のルートが見える。
- 右下にミニマップ。
- 道を敷くモード、建てるモード、交易所を開くモード（左のツールバー）。置けるマスは光らせ、費用と効果の見込みを出す。
- 素材: 地形のタイル、道（つながり方で形が変わる）、建物（今の SVG を使う。足りないものはサブエージェントに依頼）。

### CLI（AI のプレイテストのため）
- 地図全体は大きいので、範囲を指定して見る:
  - `look <町か座標> [半径]`: 周囲を文字の格子で表示
  - `overview`: 地図全体を縮めて表示（町、道、地形の大まかな形）
- `route <A> <B>`: 経路と日数の見積もり（道を敷いた場合の短縮も表示）。
- 道を敷く: `path <A> <B> [種類] [confirm]`（自動で経路を引く）。
- 交易所を開く: `found <座標> [confirm]`（候補は `sites` で一覧）。
- 置く: `place` と `civic` は今と同じ（座標は世界の座標）。

## 6. 段階
| 段階 | 中身 | 完了の目安 |
|---|---|---|
| G0 マス目の土台 | 地形の生成、シナリオの変換（町の位置と地形）、今の道をマス目の道として敷く、移動を A* に置き換え、日数を今と同じくらいに合わせる | 全シナリオのボットの結果が、今と比べて大きく変わらない（達成日数の差が1割以内） |
| G1 描画 | canvas の斜め見下ろし、カメラ（移動・拡大）、地形・道・町・隊商、ミニマップ | ブラウザで今と同じように遊べる |
| G2 町と影響圏 | 区画（D0〜D3）を世界のマス目に載せ替える。家・生産施設・需要施設が地図の上に建つ | 町の成長が地図の上で見える |
| G3 道を敷く | 小道・街道・運河・港。自動の経路引き。道なき移動 | 自分でルートを設計できる |
| G4 交易所 | どこにでも開ける交易所、新しい町の生成 | 新しい町を開いて育てられる |
| G5 追加の要素 | E1 商人の才能、E2 技術の購入・独占・使用許可、E3 音楽、E4 「結ぶ」「網を作る」目標、E5 全シナリオ解放（内容は下の 7 章） | — |
| G6 シナリオ | 8本とフリープレイの地図と目標の作り直し、手引き | 全シナリオが新しい地図で遊べる |
| F 調整 | 全員テスト、調整、公開 | 下の完了の定義を満たす |

各段階の後に、単体テスト・ボットの回帰・ブラウザの自己テストを行う。全員テストは G2 の後（町と移動が新しくなったところ）と F で行う。G0〜G2 の間は、今の路線図の版を公開ページに残しておき、G2 が整った時点で切り替える。

## 7. 追加の要素（区画方式の計画から引き継ぎ）
- **E1 商人の才能**: 雇うときに候補3人から才能を見て選ぶ（健脚、目利き、値切り上手、砂漠の民、船乗り、腕っぷし、甘党）。
- **E2 技術の購入・独占・使用許可**: 台本の自動解放を「お金で買う」形に。ライバルのいるシナリオでは先に買った側が独占し、相手は使用料を払って使う。ライバルも技術を買う。
- **E3 音楽**: 地域ごとのテーマ曲を WebAudio で合成（砂漠はヒジャーズ調、中国風は五音音階、海は長調）。ラッシュの間は変奏。音楽と効果音の音量を別々に。
- **E4 目標の型**: `link`（2つの町の間を定期便が一定回数往復）、`network`（指定した町すべてが道か航路でつながる）。マス目化で「道を通す」こと自体が目標になる。
- **E5 全シナリオ解放**: タイトル画面の設定で、好きな順に遊べるようにする。
- **E6 住民の種類**: 資料で確認できていないため保留。G2 で住居を作り直すときに、入れる価値があれば検討する。

## 8. 危険と対策
| 危険 | 対策 |
|---|---|
| 作業量が非常に大きい（本編と同等以上） | 段階ごとに区切ってコミット。G0〜G2 の間は今の版を公開したまま |
| 調整済みのバランスが崩れる | G0 で移動日数を今の路線図に合わせる。段階ごとにボットで達成日数を比べる |
| 描画が重い（1万6千マス＋家） | canvas で画面に見えるマスだけ描く。地形はまとめて画像にしておく |
| 経路探索が重い | A*＋経路のキャッシュ。道や地形が変わったときだけ計算し直す |
| CLI が遊びにくく、AI のプレイテストが高くつく | `look`・`overview`・`route`・`path`（自動の経路引き）・`sites` で、座標を手で探さなくて済むようにする |
| 道を自由に敷けると、砂漠越えなどの主題が消える | 山は通れない、砂漠の道は高価で砂嵐で傷む、海は港が要る。シナリオごとに予算や本数の上限を付けられるようにする |
| 古いセーブが読めない | 版3は地図の作りが違うため、版2以前のセーブは「新しい地図では読み込めない」と表示し、シナリオの最初から始め直してもらう（キャンペーンの達成記録と家訓は残す） |

## 9. 完了の定義
- 地図全体がマス目になり、道・交易所・生産施設・需要施設・住居が地図の上で作れる。ブラウザ版と CLI 版の両方で遊べる。
- E1〜E5 が入っている。
- 単体テスト・ブラウザの自己テストが通る。
- 全シナリオのボット回帰で、放置では達成できず、既存の目標が大きく簡単になっていない。
- 全員テストで、建設と道づくりが「楽しい判断」と評価され、必勝法の報告がない。
- `docs/balance-log.md`、`playtests/`、README を更新し、公開ページに反映する。

## 付録: 区画方式（D0〜D3）で済んでいること
- 区画の生成（地形と資源）、資源は土地に合ったものだけ（全員テスト4回目の必勝法の対策）
- 生産施設の配置（建設10日、維持費）、取り壊し、市場の圏の拡張
- 住居の自動建設と人口の上限、労働力
- 需要施設（茶館・寺院・学問所・宮殿）と満足度
- これらの単体テストと、ブラウザの区画画面

G2 で、区画の相対座標を世界のマス目の座標に置き換えて載せ替える。
