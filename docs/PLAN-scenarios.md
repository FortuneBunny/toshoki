# シナリオを版4の形にする計画

版4（開拓と糖度の版）の始まり方を、s2〜s8 にも入れる。作り替えながらバランスを取り、15回目のテストで一番大きかった「中盤が待つだけになる」も、シナリオごとに直す。

- 作成日: 2026-10-23
- 前提: 版4の H0〜H5 と F は済んだ（`docs/PLAN-pioneer.md`）。s1 とフリープレイは、町のない始まり方になっている。
- 状態: J0 と s2〜s8 の作り替えは済んだ。次は Sol と Opus による敵対的評価
- 途中で決めたこと: s4〜s8 は、調整済みの町はなるべく古い町として残し、見どころに関わる村だけを集落にした（s2・s3 のように一から作り直すと、バランスを毎回やり直すことになるため）

## 0. 方針
- **自分の交易所は、どのシナリオでもゼロから置く**。
  - 一族の館のそばに、最初の交易所を無料で置いて始める。
  - 品を作っていた村は「集落」にする。交易所の圏に入れると、自分の町になる。
- **話の柱になる町は「古い町」として最初から残す**。
  - 古い町は、今までの町と同じ。運び先・売り先になり、区画に工房も建てられる。
  - 自分の交易所ではないので、格上げはできず、交易所の数にも入らない。
  - 全部を町ゼロにすると、s4（砂漠を越えて運ぶ）や s6（海を渡る）の「遠くの大きな町まで運ぶ」形が作れない。
- **シナリオの見どころは残す**。
  - s2 糖度の流れ、s3 工房、s4 砂漠、s5 ラッシュ、s6 季節風、s7 ライバルとの白糖の勝負、s8 その全部。
- **中盤が待つだけにならないようにする**:
  - 2つで直す: ランクSを読みのご褒美にすることと、シナリオごとに読む材料を1つ足すこと。
  - **ランクSを読みのご褒美にする**:
    - 定期便を組んで待つだけのボット（新しく作る）は A か B までにする。
    - 糖度を読んで動くボットは S に届くようにする。
    - Sの日数は、この2つのボットの間に置く。
  - **シナリオごとに読む材料を1つ足す**（下の表）。読んだかどうかで、損得がはっきり分かれるものにする。

## 2. 仕組みに足すもの（J0）
- **古い町と集落を一緒に置けるようにする**:
  - 町のないシナリオの作り方（`pioneer`）に、最初からある町（`cities`）も置けるようにする。
  - ライバルの商人は、古い町から始められる。
- **目標を自分の交易所にも向けられるようにする**:
  - 定期便の往復（`link`）、街道の網（`network`）、ラッシュ（`rushes`）、品を届ける（`deliver`）の相手に「自分の交易所」を指定できるようにする。
- **海沿いの交易所を港にする**: 船を買えて、船で着けるようにする（s6）。
- **読む材料**:
  - **ライバルの隊商の行き先**（s7・s8）。町の欄と出発の画面に「サルマン商会の隊商が白糖を積んで向かっている（約3日）」と出す。
  - **古い町の食卓の入れ替わり**（s2・s8）。古い町は、食べ物の産地との行き来が日によって変わり、足りない食べ物が入れ替わる。今の「食卓にない」の印で読める。
- **待つだけのボット**:
  - 最初に定期便を組み、そのあとは新しい交易所と格上げだけをして待つ。
  - これで、どのシナリオでも「待つだけでは S に届かない」を確かめる。

## 3. 進め方
1. J0 の仕組みを入れる。
2. s2 から s8 まで1つずつ作り替える。それぞれで次を確かめる。
   - 単体テストと自己テストが通る。
   - ボット: 放置では達成できない。待つだけのボットは A か B。読むボットは S に届く。
   - Claude（Sonnet）で短い画面テストをして、手引きと見た目を確かめる。
3. 全部終わったら、Sol と Opus に各シナリオを遊ばせ、ゲームバランスを敵対的に評価させる。
   - 「待つだけで S が取れる」「ある品だけを運べば勝てる」のような抜け道を探させる。
4. 見つかったものを直し、経緯を `docs/balance-log.md` に、テストの記録を `playtests/` に書いて公開する。

## 4. 気をつけること
- 古いセーブ（s2〜s8 の町のある形）は、続きを遊べないと知らせる（s1 と同じ扱い）。
- キャンペーンの順は「安全な所で一度触らせてから本番に置く」のまま。新しい形で増えた手間（格上げ、取り込み）は s1・s2 で触らせる。
- シナリオの文と手引きは、新しい形に合わせて書き直す。
