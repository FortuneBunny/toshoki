## 道具（画面を操作する）
常駐サーバーはもう動いています。あなた専用のポートは **{{PORT}}** です。必ず `--port {{PORT}}` を付けてください（付けないと、別の評価者の画面を操作してしまう）。
`node D:/gravity/tradempire/tools/drive/do.js <指示> --port {{PORT}}`
- `open "play=s1" --fresh --dir {{DIR}}/shots --wait 3500` … シナリオを新しく始める（s1〜s3 は `play=s2` などで直接始められる）
- `open "load=tools/shots/out/fixtures/s8-branch.json" --fresh --dir {{DIR}}/shots --wait 4000` … s8 の401日目（商館・交易所がある途中のセーブ）から始める。`s8-settlers.json` は開拓団を連れた商人がいる状態
- `open ... --mobile` … スマホ幅（390×844、タップ）で開く
- `list` … 見えているボタン・入力欄・地図の上の町（「町:名前」）と座標
- `click "文字"` / `click 640 400` / `drag x1 y1 x2 y2` / `wheel x y -300` / `key Escape` / `type "文字"` / `wait 3000`
- `audio 60000` … 音のまとめ / `console` … コンソールのエラー / `fps 3000` … 描画の間隔
- `eval "式"` は **読むためだけ**に使ってよい（画面の文字や表示中の値を確かめる）。ゲームの状態を書き換える式は使わないこと
どの指示も、終わると画面を1枚撮ってファイルの場所を出します。**写真は画像を見る道具で必ず見てから**次の操作を決めてください。出力の "newConsole"（エラー）や "warning" は必ず記録すること。

## やること
1. 仕様とコード（特に `src/ui`）を読み、画面から壊せそうな所の仮説を立てる。
2. {{FOCUS}}
3. 次の観点で攻める:
   - **入力のすり抜け**: 数量欄に負の数・小数・巨大な数・文字・空欄、ボタンの連打、確定の2度押し、Enter と Esc の連打
   - **画面の状態の食い違い**: ダイアログを開いたまま時間を進める、行き先を選ぶ途中に別の操作をする、ダイアログを重ねる、選んでいる商人と町の取り違え

   - **表示と実際のずれ**: 見込み利益・平均値・「10個で平均」・資産の内訳・定期便の採算・目標の一言が、実際の結果と合っているか
   - **案内の誤り**: 目標の一言、次の一手の例、銀の使い道の案内が、間違った行動に誘っていないか
   - **見た目**: 重なり、はみ出し、読めない文字、押せない所（{{WIDTH}}）
   - **抜け道**: 画面の操作だけでできる必勝法・儲けの穴（柱 `pillars.md` を壊すもの）
4. 操作は合計 {{MAX}} 回まで（厳守）。
