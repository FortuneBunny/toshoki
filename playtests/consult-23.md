# 相談 23回目（市の場所のくじと、固定の手。Sol・Opus）

- 日付: 2026-10-24
- 目的: 22回目の作業1（固定の手を探す道具）で、s3 のいちばん強い固定の手は「隊商市の立つ町をいつも通る便」と分かった。値の候補はどれも合格しなかった（`docs/balance-log.md` の 2026-10-24 の節）。この「市の場所のくじ」をどう扱うかを、2人と相談した。
- やり方: 2巡。1巡目はそれぞれが案を出し、2巡目は相手の案を攻め、次の作業をまとめた。2人とも、ゲームの写しで探索の道具を回して確かめた。

## 分かったこと
- **市の町を通る便は、安い保険になっている**（Opus）。
  - 今の値で、蜜蜂の丘を通る固定の手は、予定の列をなくしても S 66%（線130日）。
  - 予定の列がこの便にかける負担は、中央で3日だけ。翠糖京と糖蜜町だけの固定の便は、負担が約30日。
- **町が2つのままでは、何をしても下がらない**（Opus）。
  - 市の町を袋から引いて、どの町も同じ回数にしても、蜜蜂の丘を通る便は S 45%。
  - どちらかの町を通る便は、必ず半分の市に当たる。1回当たれば S に届く。
- **町を3つにしても、交代が2回半では、くじが残る**（Opus、7001〜7200番、線130日）。
  - 泉の里を足しただけの版（Sol の1巡目の案）では、いちばん強い固定の手は S 29%、線＋3日で35%。
  - 最初の2回が蜜蜂の丘の組では S 80〜100%。泉の里かなつめ村から始まる組の多くは 0%。
  - 袋だけを足しても 31%。蜜蜂の丘の市が最初に来た組は 59〜64%、最後に来た組は 0%。
- **3つを一緒に入れると、1割を切った**（Opus）。
  - 組み合わせ: 泉の里＋市の町を袋から引く（3回で1回ずつ）＋交代を短く多く（25日、約30日に1回）。
  - 探し直した上位3つの固定の手（7001〜7200番）:
    - 線126日: S 3〜7%。
    - 線＋3日: S 5.5〜9%。
    - 線130日: S 6〜9.5%。
  - 予定の組ごとの最大は 15%。
  - 同じシードで比べると、2人を読んで回す手は固定より中央19〜34日速い。5日以上速いシードは 181〜199/200。
  - 始まってから2人を回す手と比べても、中央18〜33日速い。
  - 6001〜6200番では、2位の固定の手が S 9%、線＋3日で13%。シードの組によって、このくらい動く。
- **集計の分け方に偏りがあった**（Sol）。
  - 内訳を「その手が終わる前に始まった市」で分けていた。早く終わった遊びほど、別の組に入っていた。
  - 予定の列の最初の2〜3つ（どの手でも同じ）で分け直す。
- **間隔の取り違え**: Sol は1巡目で今の間隔を「35日＋休み14〜22日」と書いたが、正しくは「35日＋4〜12日」（一回り39〜47日）。短く多くする案は、一回り28〜33日。
- **袋の弱み**（Sol）。
  - 2回目の予告の時点で、3回目の市の町が分かる。3回目が始まる48〜53日前で、ふつうの予告より約30日早い。
  - 低迷する町と始まる日はまだ分からないが、道や荷の準備はできる。
  - 今の読む手は `knownShifts` しか見ないので、この先読みを使っていない。
- **人数を選ぶ余地は、どの案でもまだ小さい**（2人とも）。0〜1人を回すのが3日以上有利なシードは、2〜5%しかない。

## 2人が合意したこと
- **合格の条件**: Sol は1巡目の「30%に緩める」を撤回した。
  - 型の違う上位の固定の手と F* のそれぞれで、次を満たす。
    - S の線で 10%以下。
    - 線＋3日で 15%以下。
    - 予定の組（予定の列の最初の2〜3つ、どの手でも同じ分け方）ごとに 20%以下。
  - 同じシードどうしで比べて、読む手が固定より中央15日以上速い。75%以上のシードで5日以上速い。
  - 同じ判断を始まってからにした手より、中央5日以上速い。
  - 線122〜132日の数も並べて出し、急な段がないかを見る。線を動かして合格にはしない。
- **泉の里を s3 に足す**（680,120。人口480。麦3・蜂蜜0.6。初めから知っている町。市の候補はなつめ村・蜜蜂の丘・泉の里）。
- **次の作業の1番は、評価器を直すこと**:
  - 結果をシードごとに保存する。
  - 内訳は予定の列の最初の2〜3つで分ける。
  - 同じシードどうしの差を出す。
  - 始まってから回す手との差を出す。
  - 人数の有利は3日差で数える。
  - Opus の写しに原型がある。
- **人の遊びの確かめ方**: 22回目のやり方に、次の4つを足す。
  - 3回目の市の町を、予告の前に言い当てたか。それを使って先に動いたか。
  - 予告が2つ重なったとき（次の予告が今の市の最中に出る）、どちらの便の話か取り違えなかったか。
  - 判断の間隔と、予約や直しの操作の数を分けて記録する。30日を切る場面が続いて、忙しく感じなかったか。
  - 先読みできる町と、まだ分からない始まる日・低迷する町を、画面で区別できたか。

## 食い違って、まだ決めていないこと
- **袋と、短く多くを一緒に入れるか**:
  - Opus: 3つを一緒に入れる。袋は隠れた決まりにせず、「隊商市は3つの町を一巡する」と画面に出す。
  - Sol: 一括で入れるのには反対。比べる版は3つ。
    - A: 泉の里だけ。
    - B: A＋袋。
    - C: B＋短く多く。
  - Sol はさらに、袋を入れるなら、まだ市の立っていない町を画面に出すことを求めた。過去の予告から次の町を推す手も測る。
- **人数を選ぶ余地を、合格の条件に入れるか**:
  - Sol: 入れる。0〜1人が有利な場面と2〜3人が有利な場面を、それぞれ20%以上。公開情報だけで人数を選ぶ規則でも、速さの条件を保つ。
  - Opus: 今は入れない。人数を分ける仕組み（市の「買う総量」の予告、Sol の案）を別に試作する。それが通らなくても s3 の値は戻さない。
- **S の線**: 126日と130日の両方で出し、結果を見て1回だけ決める（2人とも、それ以上は動かさない）。
