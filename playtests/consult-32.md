# 32回目の相談（Opus）: 31回目の人の遊びで残った課題

- **s4 の足止め**: 人が C になった主な原因は、足止めそのものより、借金で定期便が何も買えなくなる罠と序盤の資金計画。30日の長さは固定の手の S を下げた本体なので変えない。
  - 足止め中は、その商人の給金と乗り物の維持費も止める。捕まったときに、お金の見通し（今の銀・1日の出費・何日目に借金）を出す。長老の援助は、足止め中の積荷を数えない。説明文に「30日ぶんの出費を残しておけ」。
- **s6 の港の市**: 決まりは変えない。差は1回の市に売れる量で決まるので、量を予告から読めるようにする（胡椒港の在庫・1日に入る量・頭打ち、倉庫が使えること、市で売った数）。
- **s8 の隊商市**: ライバルが市に一度も間に合わず、説明の「取り合い」と食い違う。ライバルを噂で動く形にする（市のちょうど真ん中に着くように、玻璃の都で仕入れて出る）。前半は読む人のもの。ボットでやり直す。
  - 市のあとの長い安値は、固定の手を落とす本体なので変えない。市が閉じたときに、安値の終わりと次の予告の早い日、荷の扱い方を出す。
- 順序: 値を変えない表示と s4 の手当て → s8 のライバルをボットで一度だけ評価 → 32回目の人の遊び。
