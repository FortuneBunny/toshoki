# テスト 24回目（人の遊びの確かめ。Sol・Opus）

- 日付: 2026-10-24
- 対象: 市が買う総量を予告する版の s3（de6e75c）。
- やり方:
  - 2人とも、知らないシードで CLI だけを使い、2回ずつ遊んだ。1回目は「初めての人」として、help と画面の文だけで遊んだ。2回目は経験者として遊んだ。
  - 予告が出るたびに、操作の前に「誰を何人、どこへ、いつまで、なぜ」を書き、市が閉じたあとに結果と照らし合わせた。
  - 最後に、自分の判断を、同じシードのボット（いつも1〜3人を回す手、総量を読んで人数を決める手）と比べた。
- 評価者1人ずつの試遊で、独立した人の被験者ではない（Sol の注記）。

## 見つかって直したもの
- **市の値の形**（Opus）: 市は白糖を持たずに始まり、値は初日から平ら（どの日に着いても同じ）。在庫が空のままだと値が高すぎるので、値の倍率は1.2 → 1.1 に下げた。
- **別の市への予約が「予約ずみ」と出た**（Sol）: 予約が、期間の重なりだけで判定されていた。
  - 予告から組んだ予約は、予告の番号で見る。
  - 手で組んだ予約は、隊商市の町へ行くものだけを数える。
- **臨時の便に切り替わった町で、その停泊地の積み下ろしが飛ばされた**（Opus）: 切り替わった町が新しい便の停泊地なら、そこで積み下ろし・売り買いをしてから出る。
- **閉じた市が「今」「高く買う」と出ていた。市の行に安値の残り日数が出ていた**（Sol・Opus）。
  - CLI の `status`・`shifts` と予告の画面で、安値と市の様子を分けて書く。
  - 閉じた市は「閉じた（N個を買い終えた）」と出し、商人ごとの目安を出さない。
- **達成すると、最後の市の結果が見えなかった**（Sol）: 達成の知らせのあとに、開いている市の途中の結果（売った数・同じ日に安い町で売っていたら）を出す。
- **一巡の文が紛らわしかった**（Sol）: 「この一巡で、まだ予告の出ていない町は…（決まるのは町だけ。始まる日・安くなる町・総量は、予告まで分からない）」にした。
- **CLI の `shop` の工房の文が「銀100は残す」だった**（Sol）: 実際の20に直した。

## 次の課題として残すもの
- **臨時の便の期間と着く日が、便の最初の停泊地（交易所）からしか測られない**（Opus・Sol）。翠糖京や糖蜜町から直に行けば間に合う商人が拾えない。1〜2日前に別の町を出る便も、期間に入らない。
- **積み待ちで予約を逃しても、知らせがない**（Sol）。逃したときに「積み待ちのため出られず、今回の市の売上0」を出す。締切が近いことも出す。
- **走っている臨時の便を直せない。積荷がなくても市へ向かう**（Opus）。
- **市でいくらで買うかの目安が、どこにも出ない**（Opus）。最低売値が当て推量になり、1回目は2回、全部持ち帰った。
- **初めての人の銀が尽きる罠**（Opus）: 糖蜜町の白糖の需要は細く、最低売値を高くすると売れずにたまる。その間に製糖所の自動仕入れが銀を使い切った。
- 商人の欄で「予約ずみ」が2回出る。倉庫の白糖は資産に入らない（規則どおりだが、驚く）。
- 人数の腕前は、まだボットを上回っていない。上の「直に行く」と「値の目安」が直ってから、もう一度人で確かめる。
