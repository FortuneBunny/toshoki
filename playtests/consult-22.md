# 相談 22回目（売り場の交代の次の一歩。Sol・Opus）

- 日付: 2026-10-23
- 目的: 21回目のあと、s3 の今の版の評価と、次に何をするかを、遊んだ2人と相談した。
- やり方: 2巡。1巡目はそれぞれが案を出し、2巡目は相手の案を攻め、次の作業をまとめた。Opus は今の版を回して確かめた（ゲームの写しの中だけ）。

## 分かったこと
- **固定の手はまだ止まっていない**（Opus）。
  - 21回目の表の「固定 F* 8/90」は、12個待ちのときの数字だった。
  - 待つ数を変えると、F* の S は次のとおり。
    - 14個待ち: 101〜190番で 19/90。191〜390番で 53/200。新しく使った391〜490番で 21/100。
    - 16個待ち（ボットの既定）: 17/90。
  - Sol は1巡目で「固定の手を目安まで抑えた」と判断していた。2巡目でこれを撤回した。
- **終わる日が固まる**（Opus）。
  - F*（14個待ち）では、200シードのうち34が129日ちょうどで終わる。S の線（130日）がそのすぐ上にある。
  - 世界はほぼ決まっていて、シードで変わるのは主に予定の列。S の線を1日動かすだけで、固定の手の S が1〜2割変わる。
  - 値を直すたびに、固まりの上と下を行き来していた。いたちごっこの大きな原因はこれ。
- **低迷する町のくじが大きい**（Opus）。F* は、低迷が2回とも糖蜜町なら S 58/100、2回とも翠糖京なら 8/100。
- **市の場所は必ず交互になる**（Sol）。予定を作るときに前回の市を候補から外しているので、候補が2町の s3 では交互になる。最初の1回のあとは、場所を読む必要がない。
- **「始まってから出たのでは間に合わない」は保証になっていない**（Sol）。始まってから回す手でも S 4割。
- **読む答えが、いつも同じ**（Opus）。
  - 読む手は、200シード中193で固定の手より速い。
  - 回す人数は2人でも3人でもほぼ同じ。
  - 判断の中身は「予告が出たら押す」に近い。
- **読む手のぶれ（物流の組み方で S 67〜97%）は、「物流も腕前」として受け入れてよい**（2人とも）。合格の目安は、決まった1つの土台ではなく、同じ土台で読むと固定よりどれだけ速いかで決める。

## 2人が合意した次の作業
1. **評価器と探索ボットを、1つの道具として作る（s3）**。
   - 固定の手を自動で探す軸:
     - 待つ数: 4〜20
     - 停泊地ごとの最低売値
     - 売り先の並び
     - 雇う才能
     - 技術を買う銀の額
     - 道
     - 開拓地
   - 探し方: ランダム探索のあと山登り。上位からは型の違うものを残す。
   - 同じ物流の土台ごとに、次を比べる。
     - 固定
     - 始まってから回す
     - 予告を読む（回す人数 0〜3）
     - 予定の列なし（負担の診断用）
   - シードは3つに分ける: 探索用、選抜用、最終確認用。最終確認用は新しく取り、1度使ったら調整用へ移す。
   - 集計は、低迷する町の並び・市の場所・最初の時期ごとにも出す。
   - 検定: 今の版で、「14個待ちの F* が S 2割前後」を自分で見つけ直せること。
2. **値を据え置いている間に、値以外を直す**。
   - 市の場所を毎回の抽選にする。
   - 「間に合わない」の文を、商人ごとの到着見込みに替える。
3. **探索で見つけた最強の固定の手に対して、s3 の値を1回だけ決める**。
   - 候補:
     - 低迷する町のくじの偏りを抑える（最初の2回で両方の町が1回ずつ）
     - 隊商市の値1.2
     - S の線の位置
   - 合格の条件（最終確認用の新しいシードで）:
     - 最強の固定の手が、S の線でも線＋3日でも S 1割以下。
     - 同じ土台で、読む手が固定の手より中央15日以上速い。
     - 回す人数によって、明らかに有利な答えが変わる場面がある。
     - 予告をなくすと、読む得が消える。
   - 値を決めたら、それより後では動かさない。
4. **s7 の試作を2段で行う**。
   - (a) 隊商市の在庫と値をライバルと共有する。ライバルは始まってから市へ向かう。
   - (b) (a) に、公開された予告だけを読むライバルを1便足す。プレイヤーの予約は追わせず、移動と積み直しも課す。
   - (b) を残す条件: プレイヤーの最善の人数が、シードによって0〜3人に分かれること。答えがいつも「全員で市へ急ぐ」なら (a) にとどめる。
5. **s2 で、産地の不作の予告を小さく試作する**。s8 は、s3・s7・s2 の値が決まってから組み合わせる。s4・s5・s6 には売り場の交代を入れず、もともとの出来事（盗賊・砂嵐、ラッシュとクラッシュ、季節風）を予告つきにする。

## 食い違って、まだ決めていないこと
- **低迷の重み付け**: Opus は「翠糖京2・糖蜜町1」を出したが、2巡目で取り下げた。いちばん強い固定の手をねらって崩す形に近いため。くじの偏りを抑える案だけを、候補に残した。
- **ライバルが予告を読むか**:
  - Sol: 双方が読める形を最終候補に残す。
  - Opus: 鏡合わせになって距離の勝負になるので、数字が出るまで入れない。
  - そこで、s7 の (b) の条件で決める。

## 人の遊びの確かめ方
- 知らないシードで1回だけ遊んでもらう。初めての人と経験者を分ける。
- 予告が出るたびに「どの便を・何人・いつまで、なぜ」を一言聞き、市が閉じたあとに結果と照らし合わせる。
- 記録すること:
  - 予告を理解したのに、積み待ちや帰り道で外した回数。
  - 毎回同じ押し方で済んだか。済んだなら、読みではなく作業になっている。
  - 閉じたときの差の表示を見て、得をしたと感じたか。
  - 判断1回あたり、何日速くなったか。
