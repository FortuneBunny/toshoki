## 大きな発見と対応

### 1. シュガーラッシュが起こせない（柱3が機能していない）
Sol は荷車4台と銀4万6千を持ちながら、ラッシュを1回も起こせなかった。原因を数値で追うと、
- 甘味1種類の効き目の上限が低く、町が大きくなるほど必要量が非現実的になる
- 町の人が食べる量は需要で頭打ちになり、甘味を大量に届けても消費されない

**対応**: ラッシュの条件を「糖度140以上」かつ「その日の甘味の摂取が必要量の75%以上」に変更。町が持ちたい量を超えた甘味は毎日20%ずつ余分に食べられる（ドカ食い）。結果、「よく食べている町に甘味2種類を60個ほど届けると2〜3日でラッシュ」になり、放置ではほぼ起きない（全シナリオで年0〜0.3回）。

### 2. 必勝法の抜け道（柱1を壊す）
Opus は s7 で「同じ町で白糖を買ってすぐ売り戻す」ことで取引量を水増しし、104日でSを取った。ライバルは取引量0で、対戦になっていなかった。

**対応**: 仕入れた町で売り戻した分は、目標の数に数えない。ライバルに自前の製糖所を持たせ、白糖を実際に各地へ運ぶようにした（汎用ボットの取引量の割合は17〜31%に下がり、競争になった）。

### 3. 大都市が育たない（s8）
資産が目標の7倍になっても、琥珀京の人口目標に届かなかった。大都市ほど必要な食料が膨大になるため。

**対応**: 大きな町ほど1人あたりの必要量が減るようにした（人口千人単位の -0.2 乗）。余った銀で町の成長を後押しする「寄進」を追加（人口×1.5銀、90日間、成長が25%早まる。糖度が足りない町には効かない＝食料を届けることの代わりにはならない）。

### 4. 初心者がシナリオ3で詰まる（序盤は必ずクリア、の目標を満たしていない）
Haiku は製糖所に必要な資金が貯まらず、白糖を1個もつくれなかった。

**対応**: 新しい仕組み（加工）は「安全な状況で手引き付きで触らせる」原則に沿って、s3 に製糖所の使い方の手引きを付けた。開始時の銀 450 → 750、製糖所 600 → 450 銀、白糖の目標 250 → 200、資産の目標 6000 → 5000。

### 5. 分かりにくさ（全員）
| 指摘 | 対応 |
|---|---|
| 町に何をどれだけ届ければいいか分からない | 町の画面に「伸びしろ」（1日あと何個で糖度が何上がるか）と甘味の摂取量を表示。商人がいなくても最後に見た食卓を表示 |
| 工房の状態が見えない、番号が飛ぶ | `workshops` コマンド。工房の番号を1から |
| 自動仕入れで銀が尽きる | 手元の銀が300を切ると止まる |
| 「見送り」の理由が分からない | 値段と閾値、在庫なし、積載いっぱいなどを具体的に表示 |
| 定期便の設定内容が見えない／黙って置き換わる | `order list` に設定を表示、置き換えたら通知 |
| 定期便で倉庫から積んだ品が1周遅れて売れる | 順番を「下ろす → 積む → 売る → 買う」に |
| 定期便で食料を残せない、砂漠で食料が尽きる | `keep:品*数` で残す数を指定。砂漠を渡る前に食料を自動で買い足す |
| 2人目に指示する前に時間が進む | `travel --nowait` |
| 定期便の商人が着いたところで止めたい | `wait <日数> -m <番号>` |
| `order pause` で止めると売買されない | 止めるときも、その町での売買は済ませる |
| 目標の品をまだ買い取らない町がある（s6） | 目標欄に「町が育つと買い取る」と表示 |
| 未訪問の町の人口が NaN | 修正 |
| 大口注文の品がどこで買えるか分からない | 手に入る品だけを注文に出し、産地を表示 |
| quote と trade の違い | 見積もりの出力に「確定するには trade」と明記 |
| 砂漠で食料が足りないまま出発 | 出発時に警告 |

### 6. 下手な人が「なぜ失敗したか」分からない（Luna）
後半のシナリオは失敗してもよいが、理由が本人に分かることが目標。Luna は s6 で、白檀港が香辛料を買い取らない理由（都市に育てると買い取る）が分からないまま終わった。Sol は同じ仕掛けを自力で見つけて「経済シミュレーションとして納得できた」と評価しているので、仕掛けは残し、伝え方を直す。

**対応**: s6 と s4 の導入文に、前提条件と育て方を書いた。一度達成した目標は、維持費で数値が下がっても達成済みのまま残す。盗賊の出る道では、推奨する護衛の人数（危険度×2＋1）を出発時に出す。

### 採用しなかったこと
- 「s4 の1往復が長い」（Sonnet）: 砂漠を越える長旅は s4 の主題。代わりに開始時の銀を 600 → 900 に増やし、ラクダを早く買えるようにした。
- 「糖度の計算式を全部見せてほしい」: 式ではなく「伸びしろ」で、次の一手が分かるようにした（柱1の読みの余地を残す）。
