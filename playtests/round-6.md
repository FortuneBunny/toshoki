## 新しい仕組みの評価
- **技術**: 好評。Opus は精製の秘法を26日目に独占し、ライバルから使用料720銀を得た（「独占の仕組みがきちんと報われた」）。Sol は s7 で逆に独占され、使用料を払った（「投資順序を迫る仕組みはよい」）。Sonnet は「効果が目に見えて分かりやすい」。
- **道**: Sol は「敷設済みの道を受けて費用が520銀から320銀に下がり、道を共有するネットワーク投資の面白さが見えた」。Sonnet は、街道で荷車を使えるようになって収入が跳ねた。
- **商人の才能**: 選ぶのは楽しい（Opus は砂漠の民をなつめやしの便に、甘党を甘味の便に当てた）。ただし効果を体感しにくい。
- **交易所**: 開くのは簡単。ただし育てるのが重すぎる（Opus は人口1000まで490日）。Sonnet は人口160のまま「役に立たなかった」。

## 対応
| 指摘 | 対応 |
|---|---|
| 下手な役が最初の一手を決められない（Luna） | **次の一手の例**を足した。status・`advice`・画面の右の欄に出る。知っている相場から利益の出る取引を出し、知らなければ「ここの特産を積んで、まだ知らない町へ」と勧める |
| 砂漠で食料がいくつ要るか分からない（Luna・Haiku） | `route` に「砂漠を約N日 → 食料がM個いる（今K個）」と護衛の目安を出す。食料の計算式を CLI・画面・定期便・助言で1つにそろえた。`routeInfo` の砂漠の日数が「区間の数」になっていたバグも直した |
| 定期便が品物で荷台を埋めて砂漠で飢える（Haiku） | 次の区間で砂漠を渡るなら、食料の分の荷台を空けて仕入れる |
| 工房の自動仕入れが止まってから気づく（Luna・Haiku） | 手元の銀が200を切ったら status で警告 |
| 「甘味の摂取 2/75」の単位が分からない。ラッシュまで何が足りないか（Sonnet・Sol） | 「ラッシュまで 糖度をあと N、甘味の摂取をあと M%（今日の甘味の必要量のうち食べた割合）」 |
| s5 が期限内に2回目のラッシュに届かない（Sonnet） | 期限を420日から480日に延ばした（クラッシュを18日に延ばした分と、街道の目標が増えた分）。説明文に「定期便を止めて到着をそろえ、一気に届ける」コツを足した |
| 交易所の目標が重すぎる（Opus） | 「人口600まで育てる」に下げた。放っておくと900日で550人ほどなので、交易の手は要る。`sites` に「人口160の集落から始まり、最初の産出は1日2個ほど」と明記 |
| 工房の停止通知が多い（Sonnet・Sol） | 30日に1回だけ |
| 工房の製品で荷台が埋まり、仕入れができない（Opus） | `load:品*数` で積む数に上限をつけられるようにした |
| 町が買い取らない品が分からない（Opus） | `city` に「この町が買い取らない品」を出す |
| 積荷0個の盗賊で wait が止まる（Opus） | 止めない |
| 定期便を指定した町で止めたい（Sol・Opus） | `order pause <町>` |
| 定期便の町名を日本語で書けない（Haiku） | 書けるようにした |
| まとめ買いの値上がりが見えない（Haiku・Sonnet） | `quote` に「1個目 → 最後の1個」の値段を出す |
| `heirlooms` に `--save` が要る（Haiku） | 要らなくした |
| 工房の1日の回数に技術の分が入っていない（Sol・Opus） | 入れた |
