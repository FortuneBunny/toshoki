# テスト 17回目（ゲームバランスの敵対的評価。Sol・Opus）

- 日付: 2026-10-23
- 対象: s2〜s8 を版4の形（自分の交易所はゼロから、話の柱の町は古い町）に作り替えた版。
- やり方: 仕様とソースを読ませ、CLI と、ゲームの操作だけを使うスクリプトで各シナリオを最後まで遊ばせた。世界の状態の書き換えは禁止。ランクSを狙わせ、「待つだけでSが取れる」「一つの手で勝てる」「目標の重さ」「新しい仕組みの穴」を探させた。
  - Sol: s2〜s8 をすべて最後まで。s1・フリープレイも少し。
  - Opus: s2〜s8 と、ボットとの比べ。

## 結果（直す前）
| シナリオ | 一番うまくいったやり方 | 結果 |
|---|---|---|
| s1 | 定期便を組んで待つ（ボット） | 125日 S（手引きなので問題にしない） |
| s2 | 琥珀京に一度も売らず、谷の中の交換だけ（Sol） | 219日 S（6シード中1つ。残りは A） |
| s3 | 格上げ→製糖所→翠糖京への定期便を3人に写して待つ | 141〜164日 S（2人とも6シードすべて） |
| s4 | 絹の便＋オアシスへ食べ物を運ぶ便 | 期限切れ C。オアシスは最大825人（Opus）・698人（Sol） |
| s5 | 甘味を2種類そろえて一気に届ける | 224〜226日 A（S は 216日以内）。読みが効いている |
| s6 | ダウ船の決まった巡回 | 204〜339日 A |

| s8 | 古い町に畑を置き、食べ物を琥珀京へ | 755日 B（Opus）。資産25000は放っておいても届く |

## 見つかって直したもの
- **s7: ライバルの本拠地に製糖所を建てると、ライバルの製糖が止まる**（2人とも。高）:
  - 毎日の処理で、プレイヤーの工房がライバルの工房より先にサトウキビを仕入れていた。
  - 直し方:
    - ライバルの工房を先に動かす。
    - ライバルの工房がある町には、自分の工房を建てられなくした（「材料に先約がある」）。
  - そのままでは、手引きどおりに遊んでもライバルの売上の85〜95%で届かなかった。ライバルの工房を2日に1回動くようにした。
  - 白都への固定の便は 195〜240日（4シード）。S の線を 0.45→0.4（192日）にし、ライバルの隊商の行き先を読んで売り先を分けると縮む線にした。
- **s3: 定期便を写して待つだけで S**（2人とも。高）:
  - いちばん遅い目標の「白糖を200個つくる」は、製糖所の速さだけで決まっていた。
  - 直し方:
    - 目標を「白糖を売って9000銀を稼ぐ」（市場で買った分は差し引く）に替えた。
    - 翠糖京と糖蜜町に、白糖の需要の波（80日で一回り。山がずれている）を付けた。
  - 同じ固定の便は 180〜220日の A（6シード）になった。
  - 試した読む筋書き（売り先の切り替え、谷で持ち越す）も A だった。S に届く手は、次の評価で確かめる。
- **s2: 琥珀京を無視して S**（Sol。中）と、**琥珀京のなつめやしがいつも品切れで、波を読む意味がない**（Opus。中）:
  - 直し方:
    - 目標に「琥珀京でなつめやしを150個売る」を足した。
    - 琥珀京のなつめやしの生産を6→14にした。
    - 琥珀京を「落ち着いた古い町」（人口が動かない）にした。自分で育って食べる量が増え、いつも品切れになっていた。
  - これで、琥珀京のなつめやしの値が、波に合わせて2.6〜12銀で上下する。
  - 谷の交換だけの手は期限切れ（C）になった。谷の交換に琥珀京への1便を足した固定の筋書きは、4シードすべて A（230〜272日）。
- **s4: オアシスを人口1000にする目標が届かない**（2人とも。高）:
  - 直し方:
    - オアシスのそば（市場の圏）に、小さな「ぶどうの泉」を置いた。
    - 古い隊商路の危険度を2→1に下げた。
    - 商人を4人までにした。
  - Opus の筋書きで、220〜272日の A（3シード）になった。
  - 最初に置いたぶどうの泉（人口180、ぶどう3・干しぶどう0.5）では、オアシスが75日で3000人を超えたので、小さくした（人口120、ぶどう1.2）。
- **s8: 資産25000は放っておいても届き、琥珀京8000は重い**（Opus。中）:
  - 直し方:
    - 資産の目標を40000に上げた。
    - S の線を 0.45→0.55 にした。
    - 琥珀京の畑を増やした（麦10→15、キビ5）。甘蔗平原とぶどう高原を集落にした分の埋め合わせ。
    - シナリオの文で、古い町の区画にも畑を置けることを伝える。
  - Opus の筋書きで、琥珀京は520〜570日目に大都市になった。自分の交易所の人口3000が残る。
- **工房の自動仕入れが、手元の銀100を割ると黙って止まった**（Opus）。残す銀を20にした。

## 次の課題として残すもの
- s3 は工房の速さで日数がほぼ決まる。読みが S を分けるかは、まだ確かめられていない。
- s6 は、白檀港が「都市」になる日と胡椒港の生産で決まり、季節風を読む意味が弱い（2人とも）。
- s5 はシードによるぶれが大きい（226〜428日）。
- 古い町には格上げなしで工房を建てられる（Opus）。s7 の本拠地のほかは、手引きの「格上げしてから」を飛ばせる近道として残した。
