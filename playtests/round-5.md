## 見つかったバグ
| 指摘 | 対応 |
|---|---|
| `district` に `undefined` が出る（Opus・Sonnet・Sol・Haiku） | 世界の地形から作った区画の「山」と「道」の文字がなかった。CLI と画面の両方に足した |
| 砂漠を通らない街道で「砂漠で食料が尽きた」が出て `wait` が止まる（Opus） | 砂地を横切る街道でも食料を食べていた。食料が要るのは街道のない砂地だけにした（街道には井戸と隊商宿がある） |
| 人口999で目標の表示が100%（Sol） | 段階に届くまでは99%で止める |
| 扱わない品（茶・陶器）の掘り出し物の噂（Sol） | そのシナリオの品だけにした |
| 工房の「止まっている」通知が毎日出る（Opus） | 理由が変わったときか30日ぶりのときだけ |

## 必勝法・抜け道
| 指摘 | 対応 |
|---|---|
| s7 で、自分が売った白糖をその場で買い戻して別の町で売ると、販売数に再加算される（Sol） | 販売数の競争は「市場で買った分を差し引く」＝自分の工房で作った分の勝負にした |
| 生産施設がすぐ元を取れる（茶園260銀で茶+1.1/日。Opus） | 費用を「産出の値打ちの18日分」以上にした（茶園515銀、香辛料の園691銀） |
| ラッシュの得がクラッシュの損より大きい（Opus） | クラッシュを14日→18日に（ラッシュは8日）。柱3の「代償」をはっきりさせる |
| s6・s8 が簡単（Opus 難しさ2、Sonnet 2.5） | S基準を s6 45%→40%、s8 50%→45%。s8 には「交易所を開いて町に育てる」目標を足した（G6） |

## 分かりにくさ・提案（対応したもの）
- 季節風がいつ切り替わるか分からない → `status` に「切り替わるまで あと何日」。
- 製糖所のレシピの順番を変えたい（粗糖のまま売りたい） → `workshop <番号> recipe <レシピ名|auto>`。

## 採用しなかったこと・保留
- `trade buy ... all` に予算の上限（Haiku）: `quote` で確かめられる。全員テストで再び出たら検討。
- `build`（工房）と `place`（施設）の遠隔の条件（Opus）: どちらも「商人がいるか定期便が回っている町」で同じ。定期便は自分の拠点網なので、遠隔で建てられるのは仕様とする。
- 茶（s6）と菓子（s8）の利益幅（Opus）: 費用の見直しと S 基準の引き締めで様子を見る。
