# 34回目の相談（Opus・Sol）: シュガーラッシュのデザインを見直すべきか

s4 から強盗団を外し、蜂蜜を足す案も採らなかったあと、柱3「甘い誘惑とその代償」と柱4「ドーパミンが出る手触り」の要であるシュガーラッシュを、ゲームデザインの考え方（ルール・インタラクション・フィードバック、予兆→溜め→解放→余韻、コアループとゲームサイクル）に照らして見直すべきかを、2人に遊んでもらって相談した。

## 遊んだ記録（要点）
- **Opus（s5 seed 42、365日目に B）**
  - 自分の交易所では、粗糖16個で73日目にラッシュが起きた。8日で人口 +9%。ただし、ラッシュの値で売れたのは手元の白糖4個（+127銀）だけで、次の荷は8日のうちに届かない。
  - 続くクラッシュで人口 −3%。明けたあとも育ちは1.13%/日から0.34%/日に落ちたままで、そのまま育っていた場合と比べると約20%以上の損だった。
  - 祭都では3回挑んで、3回とも外した。
    - 2日早く起きて、反動が大祭に重なった。
    - 都市に育って必要量が増え、甘味69%/70%で届かなかった。
    - 甘味を3日で食べ尽くした。
    - 定期便に任せると、大祭の外で勝手に起き、反動がまた大祭に重なった。B に届いたのは、365日を過ぎて大祭の外のラッシュも数えるようになったから。
- **Sol（s5 は233日目まで、s3 は57日目まで）**
  - s5 の大祭は3回とも逃した。自分の交易所と s3 では起こせた。
  - どちらも、火をつけるために手元の甘味を売り切っていて、ラッシュ中の追加の売上は0銀だった。
  - クラッシュでは人口が約3〜4%減り、もう一度起こしたいとは思わなかった。

## 2人の見立て（一致した所）
1. **見直すべき。** 柱3・柱4とも △。
2. **解放に中身がない。** 8日はどの便の片道よりも短く、ラッシュの値で売る2便目が間に合わない。いちばん儲かるのは、火をつけるために平常の値で売った便そのもの。
3. **代償が重すぎ、二重になっている。** 育ちが止まるうえに人口も減る。糖度の目標値も下がり、明けてからの立ち直りまで遅れる。育ちの得は8日で約+3%なのに、損は約−13%以上。自分の交易所は開拓の倍率で速く育つので、損はさらに大きい。だから「甘味を1種類に絞って避ける」がいつも正解になる（柱1の「答えが毎回同じ」）。
4. **余韻がない。** 何銀・何人の得だったかを示す決算がない。ラッシュの知らせは、町の成長などほかの知らせに埋もれる。
5. **予兆と溜めはよい。** 間近の印、損得の文、大祭に重なる警告。代償の理由も分かる罰で、理不尽ではない。ただ、クラッシュの18日はただ待つだけの時間になる。

## 直したこと（その場で）
- CLI で、ラッシュ中・クラッシュ中にも「条件はそろっている（明日にもラッシュ）」と出ていた（Sol）。今の状態と残りの日数を出すようにした。

## 決めたこと
1. **決算と予兆の表示を入れた**（再測定は要らない）。
   - ラッシュの決算（8日で売った甘味と銀・人口の増え）と、反動が明けたときの人口の増減。
   - 「今の届け方なら約◯日で線を越える」。
   - 大祭を逃したわけに、大祭の間の最高の糖度と甘味の摂取。
   - 自分の交易所と目標の町のラッシュは大きく出し、⏭もそこで止まる。
2. **反動を軽くした**（案1、ボットで合格）。
   - ラッシュの育ちの上乗せ 0.4→0.8%/日。
   - クラッシュ 18→12日。人口は減らずに、育ちが止まるだけ。
   - s5 の線は 253→249日。
3. **火入れは、既定を切で残した。**
   - ボットでは、流し続ける固定の手に火が入らず、s5 の目標が成り立たなかった。
   - 熟した日に2種類目の甘味をそろえる手間も重かった。
   - 人が狙って起こす遊びとして成り立つかは、画面だけのテストで確かめる余地がある。
