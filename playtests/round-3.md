## 確認できたこと
- **シュガーラッシュ（柱3）が機能した**: Sol は甘味を倉庫に蓄えてまとめて放出し、ラッシュを2回起こした。「利益最大化だけでは解けない点は面白く、この方向性は残してほしい」との評価。
- **抜け道は塞がった**: Opus は s7 を正攻法で達成し、ライバルの本拠地に製糖所を建てて原料を奪い合う戦い方を見つけた（「ここからの逆転は爽快だった」）。
- **大都市は育つようになった**: s8 は上手い2人ともSで達成。
- **前提の説明は効いた**: Luna は s6 で白檀港を都市に育て、香辛料の目標を達成した（2回目は0）。

## 新たに見つかった問題と対応
| 指摘 | 誰 | 対応 |
|---|---|---|
| `unload cane all` / `load ... all` で倉庫の在庫が壊れる | Haiku | **不具合**。数量の検証を追加し、`all` に対応。回帰テストを追加 |
| 資産の目標は一度達成すると、寄進で減らしても達成のまま（抜け道） | Opus, Sol | 状態の目標（銀・資産・人口・町の段階）は、全部そろう瞬間に満たす条件に戻した。一度届いて下回ったときは、その旨を表示 |
| 初心者が s3 で資金切れ（建設後の300銀がちょうど自動仕入れの下限） | Luna, Haiku | 製糖所をサトウキビの産地に建てる手引きに変更（地元で自動仕入れするので運ぶのは白糖だけ）。自動仕入れの下限 300 → 100。試算では商人1人の単純な往復で156日に達成。S の基準は 45% → 33% に縮めた |
| `load` で指定数に足りないと全部失敗 | Opus | あるだけ積む |
| 在庫や積載を超えて買うと全部失敗 | Sonnet | 買える分だけ買う |
| 食料なしで砂漠に出発できる | Sonnet | CLI では出発を止める（`--force` で強行） |
| 定期便の商人では雇用・寄進のたびに止める手間 | Opus | 定期便が回っている町なら、雇用・建設・寄進ができる（`--at <町>`） |
| 定期便に護衛を付けられない | Sol | `order add ... --guards n` |
| 工房が止まった理由が分からない | Sol, Luna | 「在庫がない」「相場が上限を超えている」「手元の銀が少ない」を表示 |
| 町を育てる目標で、何をどれだけ届ければいいか | Sonnet, Luna | status の目標の下に、続けて届けると伸びる品と1日の量の目安を表示 |
| 果実酒が甘味だと知らなかった | Opus, Sol | ルールに甘味の一覧を明記 |
| 雇用費が人数ごとに上がること | Opus | shop に明記 |
| `-m` を `--nowait` の後ろに置くとエラー | Sol, Haiku | 値をとらないフラグとして扱う |

## 採用しなかったこと
- 「s8 は海運や東の都を使わずにSが取れる。全要素を使わせる副目標がほしい」（Sol）: s8 は集大成だが、どの道具を使うかはプレイヤーの選択に任せる（柱1の判断の余地）。
- 「wait で止まる事件の重要度を選びたい」（Sol）: CLI の利便性の話で、ブラウザ版では演出と通知で解決済み。今回は見送り。
- 「s4 の1往復が長い」（Sonnet）: 2回目と同じ理由で、砂漠越えの長旅は s4 の主題として残す。
