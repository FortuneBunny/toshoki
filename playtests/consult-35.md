# 35回目の相談（Opus・Sol）: 「火入れ」は遊んで面白いか

34回目の相談で、火入れを入れた版を古い決まりのボット（甘味を流し続ける固定の手）で測り、「固定の手に火が入らない」として採らなかった。だがそれは、新しい決まりを知らないボットで測っただけだった。順番を改め、まず2人に火入れの版を遊んでもらい、面白いかを判定してもらった。よければ、その遊び方を元に新しい決まりに合ったボットを作って測る。

## 遊んだ記録（要点）
- **Opus（s5 seed 42、234日目に S）**
  - 大祭のラッシュは2回とも狙った日に起こした（182日・234日）。勝手に起きたラッシュは0回。
  - 1回目の決算は「甘味44個を2548銀、人口 4298→4773（+475人）」。手応えは十分で、もう一度狙いたくなった。
  - 2回目は、火を入れる日を、甘味の量ではなく食べ物の便が着く日で決めた。その読みがいちばん面白かった。
  - 自分の交易所は1日0.88%で育つので、ラッシュは損だと読めて、起こさなかった（柱3の選択が働いた）。
  - 熟しても1〜3日で終わった（甘味の摂取がその日の値で、1便が数日で食べ尽くされる）。定期便は熟す前日に売ってしまい、自分では火を入れられない。
- **Sol（s5 seed 42、291日目に分岐して遊び直し）**
  - 大祭の前日に熟し、「今は売らず、始まる日を合わせる」緊張が生まれた。火を入れた翌日、大祭とラッシュが同時に始まり、残した甘味で利益975銀。「明確に気持ちよかった」。
  - 熟させる荷・火を入れる荷・翌日に売る荷を分けて持つ段取りが生まれた。
  - 熟すまで供給を保つために町を何度も見て回るのは疲れた。

## 2人の判定
- **採る。ただし直してから。**
- 意図の表: C2・C3・C4・C7 と柱1・3・4 は ○。C1・C5・C6 は △（古い決まりの文が残る・クラッシュの12日は待つだけ・逃したわけが古い線で出る）。C8 は ×（定期便では火を入れられず、毎回手で止める・積む・売る）。

## 見つかった不具合と直したこと
| 見つかったこと | 出した人 | 直し |
|---|---|---|
| 同じ取引で売った2種類目の甘味が数えられない（1行ずつ判定していた） | 2人とも | 取引が終わってからまとめて判定する |
| その町の甘味を買って売り戻すだけで火が入る | Opus | 売り戻しは火入れに数えない |
| 「糖度130・摂取70%で始まる」「甘味の便を止めて大祭に合わせよ」など、古い決まりの文が残る（火入れでは甘味を止めると熟さない） | 2人とも | 火入れのときは、熟す目安・火を入れる個数・「大祭に入ってから火を入れよ」に替える |
| 大祭を逃したわけが、熟していても「甘味不足」と出る | Sol | 「熟さなかった」と「熟したのに火を入れなかった」を分ける |
| 熟しているのが1〜3日しかない | Opus | 熟す判定の摂取は、3日のうちの最高にする |
| 3日分は都市の祭都で荷車1便を超える | Opus | 火入れの量を2日分にする |
| 定期便では火を入れられない（柱5） | 2人とも | 売る品に「🔥火入れ」（CLI は fire:品）。熟していればまとめて売って火を入れ、熟していなければ火入れの分を残して売り、熟す手前なら4日まで待つ |
| 流すだけの手は365日を過ぎても B が取れない | Opus | 目標の町では、どのラッシュも数える日を過ぎたら、線を越えれば火を入れなくても起きる |

## 次にすること
- 火入れは、まだ既定を切のまま。2人が書いた遊び方を元に、火入れを使うボット（定期便の火入れを使う固定の手と、大祭の窓だけ火を入れる読む手）を作り、s5 の線と合格の目安を測り直す。合格なら既定を入にする。
- 別の件: Opus の遊びで、序盤に銀が6回尽き、定期便の残す銀（reserve）が効いていないように見えた。

## ボットで測った結果（Sol、8回目）と直したこと
- 火入れを使うボット（定期便の火入れを使う固定の手・大祭の窓だけ火を入れる読む手・開催後対応）で s5 を測ると、線279日で、確かめは6項目中1項目だけの合格だった。読む手の S は5.5%（公開版は48.5%）。
- いちばんの原因: **ふつうの売りでも火が入っていた**。熟した町にいつもの便が2日分の甘味を売ると、それだけで火が入った。読む手も、大祭の前に起きたラッシュが選抜で111回あった。これでは「火を入れる日を選ぶ」にならない。
- 直し: 火が入るのは「🔥火を入れて売る」（取引の画面。熟した町でだけ出る。CLI は `trade ... --fire`）と、定期便の火入れのときだけにした。ふつうに売っても起きない。
