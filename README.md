# 糖商記 〜Great Glucose Empire〜

**町は糖で動いている。** 相場を読み、隊商を走らせ、糖を届けて町を育てる交易シミュレーション。

2001年の名作『Trade Empires』に着想を得た、ブラウザで遊べるゲームです。インストールは不要で、CLI（テキスト）版でも遊べます。

▶ **遊ぶ: https://fortunebunny.github.io/toshoki/**

![タイトル](assets/svg/ui/logo.svg)

## どんなゲーム？
- **相場を読む**: 町ごとに品物の在庫があり、少ないほど高く、多いほど安い。他の町の相場は商人が最後に訪れた時点の古い情報しか分からない。「着いたとき、まだ高いか？」を見極める。
- **町を育てる**: 町には「糖度」（町の血糖値）がある。食べ物と甘味が届くと上昇し、人口が増えて集落から大都市へ育つ。同じ食べ物ばかりでは伸びず、食卓の多様さが鍵を握る。
- **甘い誘惑**: よく食べている町（糖度140以上）に甘味を2種類以上まとめて届けると「シュガーラッシュ」が発生。甘味が飛ぶように売れるが、そのあとには「シュガークラッシュ」が来る。
- **加工と自動化**: 製糖所でサトウキビを白糖に加工。儲かる往復ルートは「定期便」にして自動化し、次の一手へ進める。荷がそろうまで待つ、手元に残す銀を指定するなど、細かい指示も可能。
- **砂漠と海**: 砂漠では隊商が食料を消費し、盗賊も出る。海では季節風に乗れば速く、逆らえば遅くなる。
- **ライバル**: サルマン商会が同じ市場を狙ってくる。技術は先に買った側が独占し、相手は使用料を払う。
- **地図をつくる**: 世界はマス目の地図。町と町の間に小道・街道・運河を敷き、空き地に交易所を開いて新しい町を育てる。町のまわりには畑や茶館を建てられ、家は人口の増加に合わせて自動で建つ。
- **住居の求め**: 町の家は地域に合った品（塩、茶、香辛料など）を求める。町が育つほど求める品が増加。1つ欠けまでそろえば家が通常通り建ち、全部そろうと町の成長が加速する。不足していると家は少しずつしか建たない（原作の住居の需要に倣った）。
- **一族の商人**: 雇うときは候補3人の中から才能（健脚、値切り上手、砂漠の民など）を見て選ぶ。
- **地域の音楽**: 砂漠・東方・海・平原で曲が変わり、シュガーラッシュの間は曲も浮き立つ（音楽と効果音の音量は個別に調整可能）。

全8シナリオとフリープレイ（毎回ちがう地図）を収録。タイトル画面で全シナリオを解放して好きな順に遊ぶこともできます。達成すると一族の「家訓」が1つ解放され、次からのシナリオで1つだけ選んで持っていけます。どの家訓にも利点と代償があります。

## 操作（ブラウザ版）
- 商人カードの「交易」で売買、「出発」で行き先を地図から選択。
- 地図はドラッグで移動、ホイールで拡大縮小。右下のミニマップをクリックするとその位置へ移動。
- 町をクリックすると町パネルを表示。「地図の上で建てる」「街道を敷く」を選ぶと、配置可能なマスや経路が光る。画面上部の「交易所」で新しい町を開ける場所、「技術」で買える技術を確認できる。
- 交易画面は RimWorld 風。`‹ ›` で1個ずつ（Shift で10個、Ctrl で100個）、`«` で買えるだけ購入、`»` で手持ちをすべて売却。
- スペースキーで一時停止／再開、`1`〜`3` キーで速度変更。
- 進行状況はブラウザに自動で保存。

## CLI 版
Node.js 18 以上で動きます。

```sh
node cli/toshoki.js new --scenario s1 --save run.json   # はじめる
node cli/toshoki.js --save run.json status               # 状況
node cli/toshoki.js --save run.json market               # 今いる町の市場
node cli/toshoki.js --save run.json trade buy wheat 20   # 取引
node cli/toshoki.js --save run.json travel natsume       # 出発（到着まで進む）
node cli/toshoki.js --save run.json overview             # 世界の地図（文字）
node cli/toshoki.js --save run.json path 麦の里 琥珀京 road  # 道を敷く（見積もり。confirm で確定）
node cli/toshoki.js help                                 # コマンド一覧
node cli/toshoki.js help rules                           # ルール
```

引数なしで `node cli/toshoki.js` を実行すると対話モードになります。

## 開発
ビルドは不要です（素の HTML / CSS / JavaScript）。

```sh
npm run serve          # http://localhost:8123/ で開発用サーバー
npm test               # ゲームの中身のテスト
npm run bots -- s2     # 決まった戦略のボットでバランスを確認
npm run svg:check      # SVG 素材の検証
npm run shots          # 主な画面をまとめて撮る（開発用サーバーを起動してから。tools/shots/out/ に出力）
```

- `src/core/` ゲームの中身（ブラウザと CLI で共通）
- `src/data/` 品物・シナリオ・バランス定数
- `src/ui/` ブラウザの画面と演出
- `cli/` CLI 版
- `assets/svg/` SVG 素材（`assets/STYLE.md` がスタイルガイド）
- `docs/` 計画書、デザインピラー、調整の記録
- `playtests/` AI プレイテストの要約

## 作り方について
このゲームは Claude Code（Anthropic）で制作しました。素材の SVG はサブエージェントが作成し、バランスは腕前の違う複数の AI（Claude Opus / Sonnet / Haiku、Codex Sol / Luna、Gemini 3.8 Flash）に CLI 版を遊ばせて調整しています。調整の判断は `docs/pillars.md`（ゲームの柱）を基準とし、経緯は `docs/balance-log.md` と `playtests/` に残しています。
